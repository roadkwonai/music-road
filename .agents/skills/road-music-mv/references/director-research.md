# 감독 인터뷰를 제작 판단으로 옮기기

확인일: 2026-10-16. 순위가 아니라 직접 인터뷰가 확보된 국내 감독 4팀이다. 2021~2023년 제작 철학을 2026년 인기 자료로 쓰지 않는다. 아래 적용은 인터뷰를 LTX 제작에 옮긴 설계 추론이며 모델 성능 실험 결과가 아니다.

| 감독·팀 | 인터뷰에서 확인한 사실 | 제작에 적용할 판단 |
|---|---|---|
| 신우석·돌고래유괴단 | Ditto의 감정 블록이 Side A/B 구성을 이끌었다. 안무를 등장인물의 시점에 넣고 캠코더를 관계를 드러내는 매개로 사용했다. | 누가 누구를 왜 보는지 샷마다 적는다. POV·기록영상 질감·흔들림의 서사적 이유를 정한다. |
| 범진·VM Project | 촬영 전 애니매틱을 만들고 작업 밑그림으로 사용했다. 편집 후 대표 스틸의 톤과 타이틀 작업을 연결했다. | 고품질 생성 전에 음악 위 샷 순서·길이를 검증한다. 대표 프레임으로 색 방향을 정하고 인접 클립 차이를 후반에서 점검한다. |
| RIGEND | 음악과 안무의 흐름을 먼저 분석한다. 공간 깊이와 관찰자 시점을 설계하며 전환·CG보다 아티스트의 에너지·매력을 중시한다고 설명했다. | 읽혀야 할 동작을 정한 뒤 화면 크기·앵글·움직임을 선택한다. 공간 층을 분리하고 효과마다 음악적 목적을 적는다. |
| 손승희·HIGHQUALITYFISH | 음악에서 떠오른 색·질감을 세트·의상으로 옮기고 가사에 맞는 시퀀스를 만든다. 기본 컷·싱크를 잡고 필요한 효과를 후반에서 작업한다. | 구간 감정과 팔레트·재질·모티프를 연결한다. 기본 컷만으로 흐름이 성립하는지 먼저 검증한다. |

당시 답변을 모든 작품의 공식으로 일반화하지 않는다. 룸펜스는 원 인터뷰를 충분히 확인하지 못해 일반론을 채워 넣지 않았다. 렌즈 수치·조명 장비·촬영 FPS는 위 자료만으로 확정하지 않는다.

특정 작품의 인물·세트·샷 배열 대신 `감정 → 시점 → 동작 → 공간과 빛 → 편집 리듬 → 효과 목적`의 관계를 가져온다. “거장처럼” 대신 “전경 유리 너머 인물의 중경, 렌즈 비응시, 천천히 다가가 거리감 축소”처럼 보이는 조건으로 쓴다. 이는 미학적 설계이며 정밀 모델 제어가 아니다.

K-POP의 실제 관찰 구간을 새 캐스트·세계관·이미지·후반 계획으로 연결할 때는 [kpop-directing-playbook.md](kpop-directing-playbook.md)를 함께 읽는다. 감독 증언, 크레딧, 화면 관찰, 제작 추론을 구분한다.

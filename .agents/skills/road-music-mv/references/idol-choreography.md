# 아이돌 안무와 단체 군무

아이돌 퍼포먼스가 걷기·화보 포즈·시선 전환만으로 군무를 충족하는 것은 아니다. 사용자가 댄스/군무를 요청했거나 연출안에서 안무형 퍼포먼스를 선택했을 때 적용한다. 발라드·라이브·서사형 MV에 군무를 강제하지 않는다.

## 음악에서 동작까지

- 원곡의 실제 시간·프레임에 리듬 기준을 연결한다. 추정 BPM, onset 후보, 청취로 확인한 박과 마디를 구분한다. 추정 격자는 리허설용으로 표시하며 후렴·다운비트를 확인한 사실로 쓰지 않는다. 곡 제작·선정은 이 단계에 포함하지 않는다.
- `direction/choreography.json`에 안무 구간, 카운트별 발의 지지/이동·상체/팔·시선, 멤버별 변형, 대형과 대형 전환, 음악 시간/프레임, 연결 shot ID를 기록한다. 8카운트는 가능한 구획 방식이며 모든 장르의 고정 단위는 아니다. 안무는 새 캐스트·의상·공간에 맞게 설계하고 기존 그룹의 특정 루틴을 그대로 복제하지 않는다.
- 단체 장면은 각 멤버의 자리·이동 방향·발/팔 동작을 구분하고, 동작을 함께 맞출 부분과 의도한 시차를 명시한다. 포메이션의 겹침·충돌·발 지지면과 의상 움직임을 검토한다. 정면 카메라를 보는 군무는 의도된 공연으로, 인물 간 관계를 보는 서사 컷은 별도로 설계한다.
- 좌우가 중요한 포즈는 인물 자신의 해부학적 좌우와 실제 카메라에서 보이는 화면 좌우를 함께 적고, 움직이는 팔과 쉬는 팔을 구분한다. 정면 기준 좌우 대응을 회전·후면 샷에 그대로 적용하지 않는다.
- 카메라가 바뀌어도 같은 안무의 카운트/발/팔 상태가 이어지게 한다. 모든 컷을 카운트 1로 다시 시작하지 않는다. 전신 군무, 솔로/듀오 디테일과 표정 컷을 음악의 흐름 안에서 배치하며 크롭 밖의 발을 억지로 보이게 하지 않는다.
- 재사용 스틸의 관찰된 시작 자세와 명목 카운트의 동작 목표를 구분하고, 도달 가능한 첫 큐와 진입 변형을 연결한다. 대형 변경 시 모든 formation ID 참조와 파생 구도·포즈 문구를 갱신한다. 실제 I2V의 좌우 팔·발 지시는 카운트표와 대조하며, 정적 구조 검증을 이 의미 검증으로 대신하지 않는다.
- 멤버 이름을 쓰는 I2V에는 해당 샷에서 보이는 헤어·의상·화면 위치를 짧게 연결한다. 모든 카메라에 같은 좌우 순서를 강제하거나 모델이 Bible의 가상 인명을 이미 안다고 가정하지 않는다.
- 실제 I2V 입력에도 클립 안의 중간 동작을 간결하게 전달한다. 시작·끝 자세와 카운트 숫자만 쓰고 모델이 별도 안무 파일을 읽었다고 가정하지 않는다. 설치 런타임의 실제 입력 길이·잘림을 확인하고, 시간별 텍스트 지시를 쓰더라도 박자나 관절 제어가 보장된다고 보고하지 않는다.
- 리허설의 `count@frame` 표는 LTX의 정밀 제어 문법이 아니다. [LTX 2.5 공식 프롬프트 지침](https://docs.ltx.io/open-source-model/usage-guides/prompting-guide)의 단일 단락·현재형 동작·약 4–8문장 권고를 참고해, 발을 내딛고 돌아오기·팔의 이동·무릎/상체 groove가 화면에서 반복되도록 설명한다. 긴 프롬프트나 종료 참조 강도를 동작 부족의 원인으로 단정하지 않는다. 실제 실패 뒤 비교가 필요하면 후보 예산 안에서 같은 모델·seed·이미지·설정을 고정하고 동작 문단만 바꾸는 등 한 변수의 검증 가능한 수정부터 검토한다.

## 이미지와 영상 검증

- 대표 샘플에 실제 군무 시작 자세/대형이 있는 전신 컷을 포함한다. 걷는 단체 사진이나 정지 보드의 통과를 군무 생성 성공으로 표시하지 않는다. 승인된 멤버·룩·배경 키는 재사용한다.
- 중간/종료 포즈 이미지가 필요하면 image plan에 순서·음악 시간·참조 계보·후보 수를 명시하고 선택된 이미지 도구로 만든다. 문서용 안무 보드와 실제 영상 조건화 입력을 구분한다. 설치된 런타임에서 확인한 temporal image-conditioning만 쓰며, 여러 키프레임이나 텍스트의 ‘8카운트’가 박자/동작의 정확성을 보장한다고 안내하지 않는다.
- 파생 종료 이미지를 제출하기 전에 실제 시작 PNG를 표시하고 인원·좌우·대형·지지 상태를 확인한다. 틀린 시작 자세를 후속 참조로 전파하지 않는다. 결과의 좋은 구도를 활용해 새 안무 버전을 설계할 때는 원안과의 차이를 명시하고, 카운트표·대형·샷/이미지/I2V·보드를 함께 갱신해 독립 재검수한다. 원래 요청·응답은 보존하고 새 재사용 지시와 구분하며, 과거 계약을 지켰다고 소급 판정하지 않는다.
- 원곡 애니매틱까지 통과한 뒤 기존 proof 예산 안에서 어려운 **기획한 멤버 구성의 군무**를 실제 LTX 2.5로 시험한다. 생성기/모델/조건화가 달라지면 지원 여부를 다시 확인한다. 스틸·단순 줌·정지 자세를 댄스 proof로 대체하지 않는다.
- 독립 검수는 정상 속도 원곡 동기 재생에서 실제로 관찰한 인원·얼굴/의상·발 접지·팔/다리의 분리·대형 유지·동작 순서·타격 시점을 기록한다. 계획한 카운트와 실제 생성된 움직임의 차이를 구분한다. 필수 군무가 성립하지 않으면 실패 원인과 허용된 수정 범위를 확인하고 해당 부분을 보완한 뒤 전체 샷을 생성한다.

안무 구간을 추가하거나 바꾸면 treatment, performance 결정, shot/image plan, storyboard와 애니매틱의 해당 구간도 함께 갱신한다. 기존 승인 이미지·원곡과 무관한 자산은 다시 만들지 않는다.

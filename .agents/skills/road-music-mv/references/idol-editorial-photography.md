이 화보의 유명인 얼굴·옷·세트를 새 캐릭터로 복제하지 않는다. 실제 장소 사진은 공간·시점·광원 기준, 승인된 자신의 인물 이미지는 얼굴·헤어·신체·의상 디자인 기준으로 나눠 전달한다. 인물의 master 자세나 스튜디오 조명까지 야외로 옮기지 않는다.

새 프롬프트는 장소의 지평선·소실점과 앞뒤 거리, 실제 벤치·계단·난간 대비 성인의 크기, 발·좌면·손의 접촉, 그림자·환경 반사, 전경 가림과 시선을 구체적으로 적는다. 사람이 공간보다 커 보이는 포스터 배치와, 거인을 피하려다 미니어처가 되는 모호한 크기 표현을 함께 피한다. 단체 구성은 같은 높이·크기의 정면 일렬보다 장면이 요구하는 높낮이·깊이·몸 방향·대화 관계로 설계한다.

장소 원본은 새 구도의 공간 근거다. 원하는 중경·어깨너머 구도에 맞는 API 재프레이밍을 계획하고, 건축·지지면·광원 보존 의도와 원본 픽셀 동일성 보장을 구분한다. 우연히 찍힌 방문객은 보존할 비식별 배경인지, 제거해 빈 지지면을 복원할 대상인지 샷별로 정한다. 방문객 얼굴을 새 캐스트로 사용하지 않으며, 전경 방문객 뒤에 주인공을 작게 덧붙여 핵심 구도를 잃지 않는다.

인물의 master와 의상 자산이 동일한 사진 바이트라면 직접 API 입력은 그 사진 한 장으로 얼굴과 의상을 함께 전달한다. 계획의 의상→master 참조 계보는 유지하고, 실제 제출 순서와 Image N 설명을 맞춘다. 동일 이미지 중복 입력의 가중 효과를 근거 없이 주장하지 않는다.

전신·환경 롱샷, 앉은 pair, 측후면·어깨너머, 전경을 둔 근접을 음악과 이야기의 필요에 맞춰 선택한다. 모든 영상에 같은 개수나 비율을 강제하지 않는다. 실제 결과를 장소 원본과 나란히 비교한 대표 스틸이 자연스럽게 읽히기 전에는 전체 샷으로 확대하지 않는다. 얼굴·의상·해시 일치만으로 공간과 인물의 결합까지 통과시키지 않는다.

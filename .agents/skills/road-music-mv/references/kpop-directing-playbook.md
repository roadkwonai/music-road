# K-POP 연출: 근거에서 제작으로

확인일 2026-10-16. 음악 제작·청취·곡 선정은 별도 작업이다. 여기서는 전달받은 확정 음원의 구조·감정·공연 동작을 **영상으로 해석**한다. 특정 감독이나 아티스트 이름을 프롬프트에 넣는 것으로 연출 설계를 대신하지 않는다.

이번 사용자가 지정한 BLACKPINK·RESCENE·ITZY의 방향에는 [인물·패션·퍼포먼스 제작안](kpop-mainstream-playbook.md)과 [여섯 작품 관찰 등록부](kpop-mainstream-research.json)를 먼저 적용한다. 아래 aespa 연구는 선택적 SF/초현실 비교 자료로 보존한다. 인물 매력·패션·현실 공간·군무·일상/감성이 기본 후보이며, K-POP 전체나 특정 그룹을 SF라는 한 가지 룩으로 고정하지 않는다.

## 근거의 네 층

1. 감독의 직접 증언: [director-research.md](director-research.md). 해당 인터뷰의 작품·시기를 보존한다.
2. 작품 크레딧: 감독·촬영·미술·후반의 담당을 확인한다. jib·SFX·AI artist 크레딧은 개별 프레임의 구현 방법을 입증하지 않는다.
3. 실제 관찰: 원본 hash와 PTS에 결속된 프레임·접촉시트·확대 이미지·재생 검토 범위를 기록한다. 구간 관찰과 정확한 컷 경계를 구분한다.
4. 새 작품 적용: 아래 제작안은 관찰에서 도출한 설계 가설이다. LTX의 기능 또는 성공률에 관한 측정 결과가 아니다.

실제 연구 파일·작품별 상태는 [kpop-research.json](kpop-research.json)에 있다. 접촉시트의 모든 타일을 봤어도 원본해상도 전수 검수·연속 재생·음악 동기가 충족되는 것은 아니다. 자동 장면 분석도 사람/에이전트의 원본 관찰을 대체하지 않는다.

원본 확대 정정: f2397은 원형 좌석 위 인물과 검은 날개형 전경이며 얼굴 파편화로 확정하지 않는다. f2634는 전신/복도가 남은 윤곽·색 분리·노이즈/굴절이다. f3915는 소용돌이 변형 전이며 변화는 f3916 이후다. f4890은 이전 풀아웃의 연속 환경 공개다. 보이는 결과만으로 카메라 기종·렌즈 mm·실사/CG 분담을 추정해 사실로 쓰지 않는다.

## K-POP 안에서도 스타일 선택을 분리

아래는 서로 다른 기획 출발점이다. 전부 인기 통계나 작품별 전수 분석으로 검증한 분류가 아니다. 사용자 지정과 실제 음원이 우선이다. K-POP을 여성 그룹·댄스·미래 도시 하나로 고정하지 않는다.

| 선택안 | 공연·서사의 초점 | 이미지·카메라 계획 | 근거 수준 |
|---|---|---|---|
| 패션·솔로/그룹 퍼포먼스 | 인물의 표정·시선·실루엣과 단체 존재감 | 개인 CU↔전신 와이드, 멤버별 질감·색, 창틀·단순 스튜디오의 공간 앵커 | WHISTLE·Shut Down 관찰. 상세 근거는 메인스트림 제작안 |
| 일상·감성·선택적 몽환 | 생활 공간의 행동·관계, 작은 상징 소품 | 창/문/가구의 동일 지리, 부드러운 빛, 작은 소품의 연속성 | Pinball·Glow Up 관찰. 몽환과 우주/SF를 구분 |
| 안무·에너지 퍼포먼스 | 전신 대형과 개인 제스처의 상호 보완 | 안무가 읽히는 기준 와이드, 얼굴/손 CU, 공간별 팔레트 | WANNABE·LOCO 관찰. 가시 인원과 공식 구성 구분 |
| 일상·기록·서사 | 누가 누구를 왜 촬영하는지, 관계 변화 | 시점 인물·휴대폰/캠코더 화면의 소유자, 시대·기록 매체·정보 공개 순서 | 신우석 직접 인터뷰를 적용한 가설 |
| 색·재질 중심 콘셉트 | 음악의 색/질감과 미술의 연결 | 구간별 팔레트·세트·의상·소품, 기본 컷 이후 효과 | 손승희·범진 직접 인터뷰를 적용한 가설 |

| 몽환/판타지·레트로·애니메이션 | 세계의 규칙·시대·그림체 일관성 | 현실성·중력·지리·재질·복식의 허용 범위 고정 | 장르별 설계 가설, 선택 시 추가 레퍼런스 필요 |

고에너지 곡에서도 모든 샷을 더치·휩·글리치로 만들지 않는다. 안무가 읽히는 기본 프레이밍을 기준으로, 실제 음원의 구간별 사건에 변화의 이유를 배정한다. 음원 미인계 상태에서는 타임코드·BPM·후렴 길이를 발명하지 않는다.

## 이미지 선행 제작으로 옮기기

[그룹·세계관 계약](group-world-planning.md)을 정한 뒤 [이미지 절차](image-preproduction.md)를 따른다. 모든 필요한 이미지의 완성 프롬프트를 작성하고 참조 순서에 맞춰 생성한다.

- 인물 master: `character_id`, 나이 기준, 얼굴의 불변 특징, 헤어, 체형·실루엣, 중립 조명·배경. 새로운 허구 인물로 설계한다.
- 캐릭터시트: 해당 인물의 승인 identity master 또는 본인 의상 master 하나만 직접 참조해 정면·3/4·측면·후면, 표정·비율을 고정한다. 다인 시트를 개별 인물 master로 대체하지 않는다.
- 의상: `wardrobe_id`와 소유 멤버, 고정 색·소재·액세서리 위치, 허용 장소를 명시한다.
- 배경: `location_id`, 연도/시대·계절·시간·날씨·현실성, 문/창/광원/무대의 고정 배치. 인물 없는 배경도 별도로 준비한다.
- 샷 시작/필요한 종료 이미지: master·의상·배경의 참조 계보, 정확한 출연자 수/좌우 위치, 샷 크기·앵글·동작·빛·소품. 생성된 단일 프레임을 LTX 입력으로 쓰며 시트 콜라주를 그대로 넣지 않는다.

프롬프트 문장 틀: `허구 인물 [character_id]의 검수된 얼굴과 [wardrobe_id] 유지. [location_id]의 [고정 구조]와 [시대/시간/빛]. [출연자/대형]. [샷 크기/높이/기울기/시선]. [하나의 명확한 동작]의 시작 자세. [필요한 전경 가림과 여백]. 단일 장면 프레임.` 실제 생성 시 대괄호를 구체적 값으로 모두 채운다.

파일·해시·참조 계보 통과와 얼굴/의상/인원/공간의 시각적 일관성은 별개다. 독립 이미지 검수를 통과한 뒤 짧은 솔로·단체 proof로 인체 결합·동작·정체성 실패를 먼저 확인한다. 복잡한 군무·다중 모핑을 한 번의 생성으로 보장하지 않는다.

## 편집·효과와 최종 확인

원본 음원은 보존한다. 클립 생성, 기본 컷 편집, 실제 음악 동기 검토, 필요한 후반 효과, 최종 재생 검수의 근거를 각각 남긴다. LTX가 지원하지 않는 다중 이미지·오디오·종료 프레임 옵션을 발명하지 않는다. 편집 레이어로 회전·분할·텍스트·UI·빛 번짐을 구현할 수 있는지 확인하고, 다른 도구로 바꾸면 실제 사용 도구를 기록한다.

납품 전 확인: 인물 수/얼굴/의상/헤어, 공간과 시대, 손·사지·거울/그림자, 가창·연주가 요구되면 실제 동기, 컷 연결/방향/가림 전후, 번쩍임·합성 경계, 음원 보존·인코딩·전체 재생. 미확인 항목은 통과로 적지 않는다.

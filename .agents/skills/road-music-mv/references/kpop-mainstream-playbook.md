# 인물·패션·퍼포먼스 중심 K-POP MV

사용자가 BLACKPINK·RESCENE·ITZY를 지정한 이번 방향을 위한 제작 지침이다. SF는 선택형으로 두고, 얼굴의 매력·의상·행동·군무와 현실 기반 공간의 관계를 먼저 설계한다. 그룹 이름을 하나의 고정된 미학으로 취급하지 않는다. 다른 실행에서 사용자가 지정한 레퍼런스·시대·콘셉트가 우선이다.

[작품·크레딧·최신성·관찰 상태](kpop-mainstream-research.json)를 확인한다. 과거 대표작과 현재 연도 공개 후보는 분리한다. 메타데이터만 확인한 작품에 타임코드·카메라·스타일 분석을 만들어 넣지 않는다. 실제 작품 관찰 기록은 해당 등록부의 `case_root` 아래 있다.

원본 화질 정정: [새 판본 등록부](../../../../Output/kpop-mainstream-mv-highres-20261016/catalog.json)에 5편의 공개2160p와 WHISTLE 최고공개1080p를 확보·검증했다. 다음 정밀 분석은 이 등록부의 `source`를 사용한다. 아래 표의 프레임 번호·관찰 범위는 과거 파일에 결속된 이력이며, 새4K 파일의 전수 의미 검토로 승계하지 않는다. 과거 Shut Down480p와 WANNABE720p는 정밀 화질 게이트 미달의 맥락 관찰 자료다. 새4K 판본의 원본5샘플 대조와 전체 재분석은 별도 상태다.

## 먼저 고를 제작 축

다음은 **기획 옵션**이며 그룹 전체에 대한 사실·인기 통계·LTX의 전용 파라미터가 아니다. 한 작품에서는 주된 방향 하나와 보조 방향을 정하고, 같은 기본 프롬프트에 그룹명만 교체하지 않는다.

몽환적 색과 표정, 양식화된 스튜디오, 비현실적 사건, 우주/SF 배경을 같은 것으로 분류하지 않는다. 보이는 환상 요소를 숨기거나 모든 VFX를 제거하라는 규칙도 아니다. 효과의 기능과 인물 가독성을 구분해 선택한다.

## 카메라·편집을 인물과 연결

- 얼굴 CU는 표정·시선·헤어/액세서리를 식별하는 역할, MS는 상체 제스처, 전신/와이드는 의상·대형·발 동작을 읽는 역할로 계획한다. 얼굴 크기를 무작위로 바꾸는 대신 샷 기능을 적는다.
- 전신 군무의 기준 구도를 먼저 만들고 솔로 컷·로우/하이앵글·탑뷰·근접 동작을 필요한 지점에 배정한다. 모든 샷에 휩·더치·급회전을 넣지 않는다.
- 카메라가 움직이면 방향·피사체와의 거리 변화·시차·동작의 시작/종료를 명시한다. 확대만으로 달리/줌 장치를 단정하지 않으며 렌즈 mm·기종은 근거가 없으면 unknown이다.
- 인물/의상/공간이 바뀌는 컷은 손의 모양·몸의 방향·시선·화면 위치·소품의 형태·색 중 연결 기준을 정한다. 머리카락·손·옷으로 가려지는 전환은 가림 전후 동일 인물을 대조한다.
- 기본 컷만으로 인물이 읽히는지 확인한 뒤 그래픽·텍스트·분할·광선·잔상·질감을 별도 후반 계획으로 추가한다. 크레딧에 CG·jib·SFX가 있어도 개별 장면의 구현 방식으로 전용하지 않는다.

이는 제작 선택을 위한 설계 원리다. 컷 밀도·박자·후렴 타임코드는 확정 음원을 인계받아 실제 구간을 확인한 뒤 작성한다. 이전 MV의 video-only 관찰을 음악·BPM·가사 분석으로 바꾸지 않는다.

## 이미지 → 영상의 일관성

[그룹·세계관 Bible](group-world-planning.md)과 [이미지 선행 제작](image-preproduction.md)을 따른다. 멤버별 master → 캐릭터시트/의상 → 배경 → 단일 샷 기준 이미지 순서로 참조를 연결한다. 그룹 사진 한 장으로 모든 개인 identity를 대신하지 않는다.

샷 프롬프트에는 `character_id`, `wardrobe_by_character`, `location_id`, 출연자 수·좌우/전후 배치, 샷 크기·높이·기울기·시선, 한 가지 명확한 행동, 빛·재질·소품을 구체적으로 넣는다. 원작 멤버 얼굴·특정 의상·안무를 그대로 복제하는 대신 식별·배치·색·동작을 연결하는 원리를 새 허구 인물에 적용한다.

2026년 현실 기반 4인 가상 그룹은 동봉 Bible의 한 예시다. 4인·성인·현대·특정 의상을 모든 K-POP의 필수값으로 강제하지 않는다. 실제/허구 장소와 현실적/판타지 표현, 촬영 연도와 극중 연도를 분리한다.

전체 MV의 LTX 진입 전 키시트·실제 이미지 스토리보드·원곡 애니매틱을 각각 독립 검수한다. `validate_mv_context.py`와 `validate_preproduction.py --production-design ... --storyboard ... --stage animatic --animatic-review ... --bible ... --require-ready`를 통과한다. 기존 이미지-only API의 준비 상태와 구분한다. 파일·해시·참조 계보는 얼굴·의상·손·인원·배경 지리의 실제 일관성을 보장하지 않는다. 군무의 인체 결합·의도치 않은 멤버 증감은 짧은 proof에서 확인한다.

## 검토 범위의 한계

접촉시트의 모든 타일 관찰과 원본 몇 장의 확대는 원본해상도 전수 의미 검수·정확한 전체 EDL·정상속도 연속 재생과 다르다. 주석의 구간이 여러 컷을 포함하면 실제 컷 수로 세지 않는다. 확대에서 다른 장면으로 확인되면 해당 원본 체크뿐 아니라 구간 주석과 메모도 정정한다.

음악 생성·후보 청취/평가·곡 선정은 별도 음악 작업이다. 이 자료를 보완한다는 이유로 기존 음원·가사·프롬프트를 재생성하거나 변경하지 않는다.

### LUMI:4에 적용할 세 갈래

2026 현실 기반 [별도 Bible](../../../../Output/lumi4-mainstream-mv-preproduction-20261016/context/bible.json)을 사용한다. 아직 곡이 지정되지 않았으므로 특정 곡/BPM/후렴·컷 수를 선택하지 않는다.

- **패션·자신감 중심**: `city-rooftop`과 `sunlit-studio`의 무대 의상. 멤버별 솔로 CU의 시선·자세 → 같은 의상의 그룹 전신으로 연결. WHISTLE의 프레임 속 프레임과 Shut Down의 단순한 재질 대비를 새 미술로 해석한다.
- **일상·친밀감 중심**: `street-cafe`와 `coastal-road`의 거리 의상, 필요하면 `sunlit-studio`의 공연. Pinball의 반복 공간 앵커와 Glow Up의 작은 소품/창광을 응용한다. 몽환 효과는 선택값이다.

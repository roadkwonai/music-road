# 음악 맞춤 미술과 실제 촬영 같은 이미지

이미지 제작 전에 의상·촬영지/세트·소품·촬영 구도를 조사하고, 확정 음원의 정서와 구간 변화에 맞는 조합을 고른다. 유명 장소나 비싼 의상 이름만 나열하는 대신, 누가 무엇을 입고 어느 표면에서 어떤 행동을 하는지 설명한다. 조사·기획만 요청했으면 실제 API를 실행하지 않는다.

## 조사에서 제작까지

1. 인계 음원·가사와 실제 확인한 리듬/구간, 사용자 방향을 읽는다. 청취하지 않은 에너지·가사 타이밍을 확정하지 않는다. 음악 제작·후보 선정은 별도 작업이다.
2. 공식 화보/브랜드·관광청/장소·건축가/세트 제작자·필름/광학 제조사 등 1차 자료를 조사한다. URL·발행/확인 날짜·실제 본 사진/범위·관찰 내용·새 제작에 적용할 해석을 구분한다. 메타데이터가 없는 사진의 렌즈·조리개·필름을 추정 사실로 쓰지 않는다. 기존 검증 자료는 이번 곡에 여전히 맞을 때 출처와 관찰 범위를 보존해 재사용한다.
3. `references/`의 비교 기록에 후보별 곡과의 연결, 실루엣/재질/색, 공간 규모와 사람의 행동, 장단점·탈락 이유·권리 범위를 적고 선택한 항목을 `production-design`의 wardrobe/locations_sets/props/camera_lenses/lighting_color/film_look 결정에 연결한다. 모든 MV에 같은 장소·검정/은색 의상·필름룩을 재사용하지 않는다.
4. 장소는 `real`/`real-inspired`/`fictional`과 로케이션/스튜디오를 구분한다. 실제 명소의 특징을 참고해 생성한 새 풍경은 현장 촬영본이나 정확한 시설 재현으로 표시하지 않는다. 대형 스튜디오는 설계 규모, 출입구·바닥·소품 위치, 현실적인 지지 구조·조명 동기를 정한다. 초현실 크기나 SF는 자동 선택하지 않는다. 넓은 세트에도 클로즈업·듀오·깊이 있는 단체와 카메라 이동이 가능한 동선을 둔다.
5. 인물별 얼굴/헤어 기준을 유지하면서 필요한 룩 ID를 만든다. 그룹 의상은 동일 복장·같은 컬렉션·개별 스타일 중 의도한 통일도를 먼저 정한다. 아이돌 단체 무대는 같은 컬렉션을 우선 후보로 두고, 공통 팔레트뿐 아니라 소재·재단 계열·금속 장식·신발의 문법을 정의한 뒤 재단·길이·장식으로 멤버별 차이를 준다. 승인된 멤버의 룩이 기준이면 그 룩은 보존하고 나머지를 맞춘다. 색만 비슷한 정장·스포츠 재킷·드레스의 혼합을 의도 없는 그룹 통일로 취급하지 않는다. 사용자가 개별 스타일을 선택했다면 그 대조를 유지한다. 안무 시 움직임·장소의 빛과 대비를 함께 정하고, 사용하지 않을 룩·배경·소품은 생성하지 않는다.

멤버별 차별화를 요청받으면 공통 색·소재·신발과 구별할 의복 종류·전체 실루엣·레이어 위치를 따로 정한다. 새 룩의 상의/하의 조합·길이·레이어를 다른 멤버의 실제 선택 이미지와 생성 전후에 나란히 비교한다. 같은 재킷+스코트 조합에서 목선이나 주름만 바꾼 경우에는 차별화가 충분한지 확인하고, 필요하면 해당 멤버의 주된 의복 종류나 실루엣을 바꾼다. 단일 인물의 얼굴·사진성 통과만으로 그룹 안의 차별화까지 통과시키지 않는다. 동일 의상을 요청한 경우에는 그 통일 의도를 따른다.
6. **정체성 master → 새 의상 master → 해당 룩의 고정 원문 시트** 순서로 만든다. 의상 master는 기존 얼굴만 보존하면서 새 옷으로 변경하는 요청이다. 시트는 그 의상 master 한 명을 참조하고 [사용자 고정 원문](../assets/character-sheet.prompt.txt)을 변경 없이 제출한다. 고정 원문의 “clothing을 보존”을 새 의상 디자인 단계에 잘못 적용하거나, 시트 문장에 실사 레시피를 덧붙이지 않는다. 여러 룩의 시트는 본인 `character_ids`와 본인 의상 master에만 연결하고, identity master 계보를 유지한다.

룩이 바뀌면 Bible·production-design·image-plan·shot prompt와 treatment/readiness의 설명도 함께 대조한다. 이전 색·소재 설명이나 ‘이미지가 없다’는 과거 상태를 남기지 않고, 실제 선택본·미선택 시안·미제작 자산을 구분한다. 각 의상 요청에는 그 룩에 필요한 소재를 명시한다. A의 시어 원단과 B의 무광 테일러링을 공통 문장에 `as applicable`로 묶으면 소재 선택이 모호해질 수 있다. 실제 결과의 소재가 공통 컬렉션을 벗어나면 해당 master만 교정하고, 통과한 멤버를 다시 생성하지 않는다.
7. 장소의 인물 없는 anchor와 필요한 역방향/높은 시점, 반복해서 쓰는 소품의 형태/재질/크기/손잡이·소유자를 먼저 만든다. 같은 장소의 다른 시점은 검수한 anchor를 다시 참조한다. 필요한 key 전체를 독립 검수한 뒤 대표 솔로/클로즈업·듀오·단체 샷을 만든다. 표본을 실제로 표시하고 연출·자연스러움을 확인한 뒤 나머지 샷과 보드로 확장한다.

연예인 화보는 구도·빛·재질·행동 분석용이다. 공개 열람을 API 입력·재배포 허가로 해석하지 않는다. 얼굴·브랜드 로고·원작 의상/세트/샷 배열의 정확한 복제 대신 새 가상 인물과 새 의상·세트에 관찰 원리를 적용한다. 실제 사진의 생성 참조 사용 범위가 확인되지 않으면 텍스트 관찰만 사용한다.

## 실사형 프롬프트의 구체화

다음은 자연어 룩 목표다. GPT Image의 카메라·필름 제어 파라미터나 실제 물리 촬영의 증거가 아니다. 실사형일 때만 적용하고 애니메이션·의도적 양식화에는 그 표현 규칙을 쓴다. 서로 충돌하는 렌즈/필름·조명을 한 샷에 쌓지 않는다.

- **구도/카메라 위치**: shot-size, 화면의 위/아래 경계, 카메라 높이와 피사체까지의 거리감, 전경/중경/후경과 시선·몸 방향을 쓴다. CU라면 `crown to upper chest; face and shoulders dominate; waist, lap and knees outside frame`처럼 실제 크롭을 지정한다. 광대한 배경을 모두 보여 달라는 문장을 CU에 함께 넣지 않는다. 광각은 공간/깊이에, 보통~긴 화각의 거리감은 얼굴/의상 세부에 쓰는 후보이며 정확한 초점거리 실현을 보장하지 않는다.
- **빛**: 태양/창/대형 소프트박스/세트 practical 중 주광원을 정하고 방향·높이·시간, 바운스와 반대쪽 그늘을 설명한다. 인물·옷·바닥·배경은 같은 광원 아래 있어야 한다. 여러 방향의 무동기 림라이트, 모든 면의 같은 밝기, 과도한 HDR 발광을 기본으로 쓰지 않는다.
- **피부/재질**: 피부의 미세한 색 변화와 적당한 texture, 광원 구조에 맞는 눈 반사, 헤어의 가닥/잔머리, 직물의 조직·봉제·중력에 따른 주름, 금속/가죽의 서로 다른 반사 응답을 구체화한다. `flawless`, `porcelain`, `perfectly symmetrical`, `hyper-detailed 8K` 같은 미용 과장은 자연스러움의 근거가 아니다. 과도한 피부 결점이나 거친 grain을 추가하는 방식으로 바꾸지 않는다.
- **공간/행동**: 자연스러운 무게 이동·어깨/골반 각도·시선, 발이나 좌면/손의 실제 접촉, 발 아래 그림자와 바닥/벽의 색 반사, 전경 가림과 깊이를 쓴다. 넓은 장면에서도 사람을 같은 크기의 오려 붙인 일렬 포스터로 만들지 않는다. 걷는 시작 프레임은 한 발의 실제 지지를 정하고, 이후 걸음은 I2V 지시로 분리한다.
- **필름/마감**: 사용할 때만 부드러운 하이라이트 전이·절제된 채도/contrast·약한 grain을 정한다. halation/bloom은 광원과 강한 하이라이트 근처에만 제한한다. 모든 픽셀의 번짐·같은 크기의 디지털 노이즈·플라스틱 광택·과한 sharpening으로 만들지 않는다. ‘35mm film-inspired AI image’는 실제 필름 촬영과 구별해 기록한다.
- **연속성**: 얼굴·연령·헤어는 공통 master, 의상은 해당 룩 master, 공간은 해당 anchor에 결속한다. 고유 액세서리의 해부학적 좌우와 화면 좌우를 구별한다. 측면에서 보이지 않는 귀의 장식을 카메라 쪽 귀로 옮겨 보여주지 않는다. 새 룩에서 액세서리 변경을 허용했으면 룩 계약에 먼저 명시한다.

프레임 안에 정수리·턱·고유 장식이 보여야 한다면 단순히 CU라고 쓰는 데서 끝내지 않고, 작은 상하 여백과 해당 귀를 가리지 않는 헤어 배치를 정한다. 잘라도 되는 ECU와 구분하고, 장식을 반대 귀에 새로 만들지 않는다. 크롭 밖의 발·계단·세트 전체를 동시에 보여 달라고 하지 않는다. 지지면이 화면 밖인 샷에서는 접촉을 유지할 조건과 실제로 보여 줄 범위를 분리한다.

계단에서 내려오는 동작처럼 출발 지지면이 필요한 경우에는 시작 이미지에 어느 멤버의 어느 발이 어느 단 위에 있는지 읽혀야 한다. 배경에 계단이 있다는 사실만으로 인물이 계단에 서 있다고 판정하지 않는다. 앉거나 내려오는 장면은 선택한 시점의 실제 배경에 필요한 좌면·계단이 보이는지도 대조한다. 같은 장소라는 이유로 계단이 없는 역방향 이미지를 고르거나 모든 카메라면에 같은 랜드마크를 억지로 넣지 않는다. 표본에서 발견한 크롭·출발 자세의 문제는 같은 문구가 있는 미생성 샷에도 확인하되, 통과한 이미지와 키를 다시 생성하지 않는다.

출연 인원·구도·시작 자세를 바꾸면 구조화된 camera/action과 참조 순서를 기준으로 파생 pose/physical-blocking·invariants 보조 조건·이미지 프롬프트·I2V 문구를 함께 대조한다. 특히 실제 참조 배열의 Image N 역할, 화면 안/밖 지지면, 이전 의상 색과 옛 좌식·퇴장 지시가 남지 않았는지 확인한다. 보조 조건에 같은 카운트·포즈를 중복 저장하기보다 기준 상태를 연결하고, API에는 해당 시점의 보이는 자세를 완성한다. API는 로컬 안무 JSON 경로를 읽지 못한다. 사용자가 준 원문과 이미 제출한 API 기록은 소급 재작성하지 않는다.

```text
[Optional single restrained film-inspired finish]. No text, logos, extra people or collage.
```

## 실제 이미지의 통과 조건

프롬프트에 쓴 것과 실제 보이는 것을 대조한다. 얼굴/옷 일치만으로 실사 자연스러움·곡 적합성까지 통과시키지 않는다.

- 같은 멤버 얼굴·헤어·연령과 선택한 의상, 액세서리 좌우, 그룹 인원/배치가 맞는가.
- 멤버별 차별화를 요청했다면 다른 멤버의 실제 룩과 비교했을 때 의복 종류·전체 실루엣·레이어 위치가 구분되는가. 공통 컬렉션의 색·소재·신발도 유지되는가.
- CU/MCU/전신·높은/낮은 시점·시선과 몸 방향이 실제로 보이는가. 넓게 생성된 샷을 CU로 이름만 바꾸지 않았는가.
- 몸의 무게·손/발/좌면의 지지, 원근·축척·가림·반사/그림자와 배경의 빛·선명도가 자연스러운가.
- 직물·피부·금속이 각기 다른 재질로 보이고 눈/치아/손/머리카락/옷의 가장자리가 뒤틀리지 않았는가.
- 곡의 구간별 룩과 공간 변화가 읽히며, 명소 소개나 같은 정면 화보의 반복으로 끝나지 않는가.

실패는 해당 자산·원인·이미지 SHA와 연결하고 정해진 수정 횟수 안에서 그 자산만 교정한다. 사용자의 새 장소/의상 지시는 새 계약으로 기록하며, 과거 방향의 자동 제출을 멈추고 기존 파일·프롬프트·검수는 보존한다. 사용자가 보여 달라고 했거나 시안 확인을 위임한 경우 실제 PNG를 표시한다.

## 촬영 원리의 확인 근거

확인일 2026-10-17. 아래 실제 촬영 원리를 이미지 생성의 시각 목표로 번역했다. 생성기가 해당 장비/후반 도구를 실행한다는 뜻은 아니다.

- [ARRI Lighting Handbook](https://www.arri.com/resource/blob/83996/409091c612f371b0c68b41d9dcb636db/arri-lighting-handbook-english-data.pdf), 인쇄 pp.12–17: key가 형태를 만들고 부드러운 fill이 그림자를 조절하며, 표면의 확산/정반사와 그늘이 재질을 드러낸다. 분리광은 항상 필요하지 않다. ‘한 개의 지배적인 빛 방향’은 램프 1대나 눈 반사 1개 강제가 아니다.
- [Kodak Essential Reference Guide](https://www.kodak.com/content/products-brochures/Film/kodak-essential-reference-guide-for-filmmakers.pdf), Antihalation Backing·Graininess and Granularity: halation은 필름 내부 반사/산란과 관련되고 항할레이션 층은 이를 줄인다. grain의 시각적 인상과 측정값도 다르다. 과도한 번짐/노이즈를 실사 필수값으로 쓰지 않는다.
- [ARRI Film Lab](https://www.arri.com/en/learn/camera-systems/tools/arri-film-lab): grain·detail·color·halation·gate weave는 별개의 후반 표현 요소다. 이 구분을 필요한 룩 문장으로만 사용한다.
- [ZEISS의 Working distance and perspective 절](https://lenspire.zeiss.com/photo/en/article/macro-and-close-up-shooting-especially-outdoors/): 거리와 원근을 함께 고려한다. 이번 확인은 공식 도메인 검색 색인 본문이며 직접 페이지 본문은 반환되지 않았다. 렌즈명 하나로 얼굴 원근을 보장하지 않는다.
- [David Mullen ASC의 실무 답변 #1602](https://reduser.net/threads/ask-david-mullen-anything.2860/page-81), 2009-02-16: 흐린 날 negative fill을 쓰는 설명을 그늘 쪽 반사를 줄이는 목표로 참고한다. 제3자 포럼에 실린 촬영감독 본인 발언이며 제조사 규격이 아니다.

화보에서 실제 관찰한 실루엣/구도 원리는 [아이돌 화보 지침](idol-editorial-photography.md)과 연결한다. 특정 촬영지·의상은 매 곡의 리서치에서 선택하며 위 예시를 장소/옷의 고정 목록으로 쓰지 않는다.

# 장르·형식과 이미지 선행 제작 확장

2026-10-16. 사용자는 발라드·록발라드·트로트 등 음악 장르, 아이돌·라이브 등 영상 형식의 다양한 조합과 맞춤 레퍼런스 분석·기획을 요청했다. 필요한 캐릭터시트·배경 등은 내장 image_gen으로 먼저 만들고 캐릭터 일관성을 유지한 뒤 LTX 2.3 제작에 들어가도록 기존 하네스를 확장했다.

음악 장르/편곡 버전, 영상 형식, 화면 look, 실제/가상 공연을 분리했다. 장르별 기본안은 제작 권고이며 사용자 선택과 실제 음악이 우선한다. 기존 아이돌/해외팝 코퍼스 외 장르·공식 라이브 비교 후보 9건을 추가했다. 일부 공식 음원 인기 근거를 확인했으나 대부분 과거 자료이며 미관찰 프레임 분석 결과나 현재 MV 인기 지표로 확대하지 않는다.

캐릭터 master·개인 시트·의상·장소 배경·샷 단일 기준 이미지의 참조 DAG와 완성 프롬프트를 계획한다. 새로운 mv_art_director가 내장 image_gen 결과를 visuals/에 기록하고, 독립 reviewer의 이미지별 hash/pass를 LTX 생산자가 소비한다. 기획-only는 프롬프트까지만, 이미지-only는 이미지 검수까지, 전체 MV는 검수한 단일 프레임으로 LTX와 편집까지 실행한다. 기존 승인 자산·실제 공연 원본은 필요한 범위에서 재사용한다.

기계 게이트는 PNG/JPEG/WebP 실제 파일·SHA256·크기·cast/location/keyframe 계보·독립 검수 기록을 검사한다. 얼굴·공간·포즈의 의미는 자동 판별하지 않으므로 실제 시각 비교가 필수다. 여러 인물이 한 개인 시트에 섞이거나 필수 자산/검수가 없으면 ready가 될 수 없다. 빈 shots는 초안이며 LTX 진입을 허용하지 않는다.

변경 범위: 기존 MV 스킬·참조·JSON DAG·예시·5개 역할·사용 안내, 새 validate_preproduction.py와 그 회귀 테스트. 실제 새 곡/캐릭터/장소가 지정되지 않은 시스템 수정이므로 실제 이미지나 영상을 생성하지 않았다. 앱/CLI/renderer의 기존 사용자 변경, 전역 설정, 설치 모델은 수정하지 않았다. 새 의존성은 없다.

완료 증거는 upstream 구조 검사, skill/spec 검사, 실제 파일 fixture 기반 새 게이트 회귀, 기존 프레임 도구 회귀, npm test, 독립 코드/사용 시나리오 검증이다. 별도 이미지 생성 도구 API wrapper나 앱 UI를 만들지 않고 기존 내장 도구와 LTX/ffmpeg를 연결한다.

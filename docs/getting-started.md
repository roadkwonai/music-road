# 시작하기

[Road Music](../README.md) · [문서 지도](README.md) · [릴리스 노트](../releases/README.md)

맥에 Road Music을 설치하고 첫 곡과 첫 영상을 만드는 데까지 안내합니다. 기능별 자세한 설명은 [상세 가이드](guide.md)에 있습니다.

## 1. 준비물

| 항목 | 기준 | 확인 방법 |
|---|---|---|
| 맥 | Apple Silicon(M1 이상) | ` 메뉴 → 이 Mac에 관하여 → 칩 |
| macOS | 14(Sonoma) 이상 | 같은 창의 macOS 버전. 엔진이 쓰는 MLX가 macOS 14부터 지원합니다 |
| 메모리 | 최소 16GB, 권장 32GB | 같은 창의 메모리 |
| 여유 공간 | 18GB 이상 | 엔진 약 8.5GB + 설치 중 임시 파일. 곡과 영상은 따로 필요합니다 |
| ffmpeg | Homebrew로 설치 | 터미널에서 `ffmpeg -version` |
| 인터넷 | 엔진 설치 때 약 12GB를 받습니다 | |

ffmpeg가 없으면 Homebrew로 설치합니다. ffmpeg는 MP3 변환, 음악 파일 불러오기, 영상 만들기에 쓰입니다.

```bash
brew install ffmpeg
```

인텔 맥에서는 이 dmg(arm64 전용)가 열리지 않습니다. 소스로 실행하면 앱은 열리지만 AI 엔진은 설치할 수 없습니다.

## 2. 설치

### 2.1 dmg 준비

dmg 파일을 받았다면 2.2로 넘어갑니다. 소스에서 직접 만들 때는 아래를 실행합니다. 자세한 절차는 [dmg 패키징](packaging.md)에 있습니다.

```bash
cd music-road
npm install
npm run dist:mac      # 결과: dist/RoadMusic-현재버전-mac-arm64.dmg
```

### 2.2 Applications로 옮기기

1. 받은 `RoadMusic-버전-mac-arm64.dmg`를 두 번 눌러 엽니다.
2. 열린 창에서 `Road Music`을 `Applications` 폴더 아이콘 위로 끌어 놓습니다.
3. Finder 사이드바에서 dmg를 꺼냅니다(⏏).
4. Launchpad나 `응용 프로그램` 폴더에서 `Road Music`을 엽니다.

### 2.3 처음 열 때 나오는 경고

이 dmg는 Apple 개발자 인증서로 서명하거나 공증하지 않았습니다. 그래서 처음 열 때의 동작은 파일을 어디서 받았는지에 따라 다릅니다.

- **이 맥에서 직접 빌드한 dmg:** 경고 없이 열립니다.
- **인터넷, 메신저, AirDrop으로 받은 dmg:** "Apple은 'Road Music'에 Mac을 손상시키거나 개인정보를 침해할 수 있는 악성 코드가 없음을 확인할 수 없습니다"라는 창이 뜹니다. 이 경우 아래처럼 엽니다.
  1. 경고 창에서 `완료`를 누릅니다.
  2. ` 메뉴 → 시스템 설정 → 개인정보 보호 및 보안`으로 갑니다. 아래쪽 보안 항목에 "'Road Music'이(가) 차단되었습니다"가 보입니다. 그 옆의 `그래도 열기`를 누릅니다.
  3. 암호나 Touch ID로 확인하면 열립니다. 다음부터는 묻지 않습니다.

  터미널을 쓸 수 있으면 아래 한 줄로도 됩니다.
  ```bash
  xattr -dr com.apple.quarantine "/Applications/Road Music.app"
  ```

"손상되었기 때문에 열 수 없습니다"가 나오면 dmg를 다시 받으세요. 그래도 같으면 위 `xattr` 명령을 실행합니다.

### 2.4 dmg 없이 소스로 실행하기

코드를 고치면서 쓸 때는 dmg가 필요 없습니다.

```bash
cd music-road
npm install
npm start
```

dmg로 설치한 앱과 소스로 실행한 앱은 같은 데이터 폴더를 씁니다. 그래서 한쪽에서 설치한 엔진과 곡을 다른 쪽에서도 그대로 씁니다. 다만 두 개를 동시에 켜지는 마세요.

## 3. AI 엔진 설치

앱을 처음 열면 **AI 음악 엔진** 화면이 뜹니다. 나중에는 가운데 열의 `설정 · 도구 → AI 엔진 (설치 · 사양 확인)`에서 다시 열 수 있습니다.

1. **설치 위치 확인:** 화면 위쪽 `설치 위치`에 경로와 여유 공간이 나옵니다. 내장 디스크가 모자라면 설치하기 **전에** `변경`을 눌러 다른 디스크를 고릅니다.
2. **엔진 카드 확인:**
   - **ACE-Step 1.5:** "설치 가능"이 보여야 합니다. 그래픽카드 줄에 `Apple M1 …(메모리 GB)`이 나옵니다.
   - **YuE2:** 맥에서는 "이 PC에는 설치할 수 없음"으로 나옵니다. NVIDIA 전용이라 정상입니다.
   - 메모리가 32GB보다 적으면 노란 `!` 경고가 붙습니다. 그래도 설치할 수 있습니다.
3. **설치:** ACE-Step 1.5의 `설치`를 누르고, 확인 창에서 `확인`을 누릅니다. 아래 단계가 차례로 진행됩니다.

   | 단계 | 하는 일 |
   |---|---|
   | 그래픽카드 확인 | 칩과 메모리 확인 |
   | 설치 도구 준비 | 파이썬 패키지 관리자 `uv` 받기 |
   | 파이썬 준비 | 앱 전용 Python 3.12 받기 |
   | ACE-Step 받기 | GitHub에서 엔진 소스 받기 |
   | AI 엔진 설치 | PyTorch·MLX 등 라이브러리 설치(화면에는 약 4GB로 나오지만 맥에서는 약 1.3GB) |
   | 음악 모델 다운로드 | Hugging Face에서 모델 받기(약 7.7GB) |
   | 엔진 점검 | 맥 GPU(Metal)를 인식하는지 확인 |

   인터넷 속도에 따라 10~40분 걸립니다. `자세히 보기`를 누르면 설치 기록이 보입니다.
4. 끝나면 카드가 "설치됨"으로 바뀝니다. `시작하기`를 누릅니다.

엔진 없이 둘러보려면 `엔진 없이 시작`을 누릅니다. 이 상태에서도 곡 불러오기와 영상 만들기는 됩니다.

## 4. 첫 곡 만들기

왼쪽 열에서 곡을 만듭니다.

1. **가사:** `가사` 칸에 적습니다. `[Verse]`, `[Chorus]` 같은 구간 태그를 붙이면 곡 구조가 좋아집니다. 태그 없이 붙여 넣어도 4줄 이상이면 앱이 태그를 붙여 줍니다.
   ```
   [Verse]
   밤하늘 아래 길을 걸어
   바람이 노래를 불러

   [Chorus]
   오늘 밤을 노래해
   ```
   가사 없이 만들려면 `가사 없이 (연주곡)`을 켭니다.
2. **곡 제목:** 가사 칸 위의 `곡 제목`에 적습니다. 비우면 첫 가사 줄로 정해집니다.
3. **스타일:** 프리셋 칩(예: `시티팝`, `발라드`)을 누르거나 `스타일` 칸에 영어 단어를 쉼표로 나눠 적습니다.
   - 예: `Korean pop, bright synth, upbeat drums, female vocal, 110 BPM`
4. **아래 줄 설정:**
   - `엔진`: `ACE-Step 1.5`
   - `길이`: `자동`, 1·3·5·10·30초, 1~6분 또는 `직접 입력` (초 단위)
   - `효과음 (실험)`: ACE-Step으로 1~30초 음향 생성. 스타일 칸에 원하는 소리를 영어로 설명합니다. 10초 미만은 생성 후 잘라 저장합니다.
   - `한 번에`: 1곡
5. **`곡 만들기`를 누릅니다.**
   - 가운데 목록 맨 위에 만드는 중인 카드가 생깁니다.
   - 단계는 "모델 불러오는 중 → 곡 구성 짜는 중 → 노래 만드는 중 → 저장하고 가사 시각 맞추는 중" 순서로 진행됩니다. 남은 시간도 함께 나옵니다.
   - 첫 곡은 모델을 불러오느라 1~3분 더 걸립니다. M1 Ultra에서는 50초짜리 곡을 처음 만들 때 122초 걸렸습니다.
   - 만드는 중에 `곡 만들기`를 다시 누르면 대기열에 들어갑니다.

<a id="toc-5"></a>

## 5. 듣고 저장하기

- 곡 카드의 `▶`를 누르면 미니 플레이어가 열리고, 가사가 노래에 맞춰 따라 나옵니다.
- 곡 카드를 누르면 아래에 상세 패널이 열립니다.
  - `⤓ MP3`, `⤓ WAV`: 원하는 곳에 저장
  - `⤓ 가사 SRT`: 가사 자막 저장
  - `폴더 열기`: Finder에서 곡 폴더 열기
- 매번 MP3로 받으려면 `설정 · 도구`에서 `완성되면 MP3로 자동 저장`을 켭니다.

## 6. 첫 영상 만들기

오른쪽 열이 영상 스튜디오입니다. 안 보이면 상단의 `음악 스튜디오` 버튼을 누릅니다.

1. 곡 카드를 누르거나, 곡 카드 앞 체크박스로 여러 곡을 고릅니다.
2. `미리보기 준비`를 누릅니다. 음원을 합치고 스펙트럼을 분석합니다.
3. `▶`로 미리 봅니다. 아래 옵션에서 배경, 스펙트럼 모양, 색, EQ를 바꾸면 미리보기에 바로 반영됩니다.
4. `영상 제작 옵션 → 렌더링`은 `GPU (Apple)` 그대로 둡니다. 맥 GPU로 인코딩합니다. 실패하면 앱이 `CPU`로 바꿔 두니 다시 누릅니다.
5. `영상 만들기`를 누르고 저장할 곳을 고릅니다.
6. 끝나면 결과 줄에 경로가 나옵니다. `타임스탬프 복사`를 누르면 유튜브 설명란용 챕터 목록이 복사됩니다.

## 7. 파일이 저장되는 곳

| 무엇 | 위치 |
|---|---|
| 만든 곡 | `~/Documents/YueStudio/Songs/<프로젝트>/<날짜시각>_<제목>/` |
| 앱 설정, 기록(`app.log`) | `~/Library/Application Support/Road Music/` |
| AI 엔진과 모델(약 8.5GB) | `~/Library/Application Support/Road Music/engines/ace-step/` |
| 파이썬 도구 | `~/Library/Application Support/Road Music/runtime/` |

`YueStudio`는 원본 앱의 옛 이름이 폴더명으로 남은 것입니다. 곡 저장 위치는 `설정 · 도구 → 곡 저장 → 옮기기`로 바꿀 수 있습니다.

<a id="toc-8"></a>

## 8. 지우기

1. `응용 프로그램`에서 `Road Music`을 휴지통으로 옮깁니다.
2. 엔진과 설정까지 지우려면 아래 폴더를 지웁니다. 약 8.6GB입니다.
   ```bash
   rm -rf ~/Library/Application\ Support/Road\ Music
   ```
3. 엔진 화면에서 설치 위치를 `변경`했다면 그 폴더 안의 `Road Music` 폴더도 지웁니다.
4. 만든 곡은 `~/Documents/YueStudio/Songs`에 그대로 남습니다. 필요 없으면 직접 지웁니다.

<a id="toc-9"></a>

## 9. 막히면

- **엔진 설치 실패:** `자세히 보기`의 기록과 `~/Library/Application Support/Road Music/app.log`를 확인합니다. 인터넷이 끊겼다면 `다시 설치`를 누릅니다. 받아 둔 파일은 다시 씁니다.
- **"맥의 GPU(Metal)를 인식하지 못했습니다":** macOS를 최신으로 올린 뒤 `다시 설치`를 누릅니다.
- **MP3 저장이나 영상 만들기에서 ffmpeg 오류:** `brew install ffmpeg`를 했는지 확인합니다. ffmpeg가 Homebrew가 아닌 곳에 있으면 [상세 가이드 10장](guide.md#10-데이터와-설정-파일)을 보고 `settings.json`에 경로를 넣습니다.
- **곡이 느리거나 메모리가 모자람:** 다른 프로그램을 닫습니다. 16GB 맥에서는 `길이`를 짧게 둡니다.

더 많은 경우는 [상세 가이드 13장 문제 해결](guide.md#13-문제-해결)에 있습니다.

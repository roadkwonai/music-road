# Road Music 상세 가이드

Road Music 1.3.0의 모든 기능을 화면 순서대로 설명합니다. 설치와 첫 곡은 [시작하기](getting-started.md)에 있습니다.

> 이 문서는 맥(Apple Silicon) 기준입니다. Windows에서 다르게 동작하는 부분은 따로 적었습니다. 현재 소스 코드(`electron/`, `renderer/`)를 기준으로 설명하며 실제 검증 범위는 [CLI 검수 결과](cli-qa-report.md)를 참고합니다.

## 1. 화면 구성

```
┌ 상단: 로고 · 버전 · 언어 · [음악 스튜디오] · RAM 게이지 · 칩 이름 · [프로그램 정보] ┐
├──────────────────────┬──────────────────┬───────────────────────┤
│ 왼쪽: 곡 만들기      │ 가운데: 프로젝트  │ 오른쪽: 영상 만들기    │
│ 가사 / 스타일·장르   │ 곡 목록 · 대기열  │ 미리보기 · 옵션        │
│ 악기·템포·구조       │ 설정 · 도구       │ 스펙트럼 · EQ          │
│ [곡 만들기] 엔진 길이 │ 선택한 곡 상세    │ [영상 만들기]          │
└──────────────────────┴──────────────────┴───────────────────────┘
```

- **오른쪽 열**은 상단 `음악 스튜디오` 버튼으로 숨기거나 보일 수 있습니다. 숨기면 왼쪽 열이 넓어집니다.
- **상단 게이지**는 메모리 사용량을 보여 줍니다. 85%를 넘으면 노란색, 95%를 넘으면 빨간색이 됩니다.
- **버전**을 누르면 프로그램 정보가 열립니다.
- 창의 최소 크기는 1000×700입니다. 실제로는 가로 1280 이상이 편합니다.
- 창을 닫으면 앱도 끝납니다. 영상을 만드는 중이면 계속할지 먼저 묻습니다. 곡을 만드는 중이면 묻지 않고 그 곡을 멈춥니다. 다시 켜면 그 곡이 대기열에서 이어지거나, 미완성 곡으로 남아 눌러서 이어 만들 수 있습니다.

## 2. AI 엔진

### 2.1 두 엔진 비교

| | ACE-Step 1.5 | YuE2 |
|---|---|---|
| 맥 | **됨** (Metal: MLX·MPS) | 안 됨 (NVIDIA CUDA 전용) |
| 만드는 방식 | 곡 구성 → 노래 생성 → 저장, 가사 시각(LRC)을 함께 기록 | 악보(ABC) 작곡 → 노래 → 소리 합성 |
| 속도 | 3분 곡 약 2~3분(원본 안내), M1 Ultra 실측 약 117초 | 3분 곡 약 8~20분 |
| 전용 기능 | 소리 커버, 녹음으로 곡 만들기, 정확한 가사 자막 | 악보만, 악보 보기·편집, 악보 커버, MIDI·ABC 불러오기, 고급 설정 |
| 받는 양 / 필요 공간 | 약 12GB / 18GB | 약 11GB / 약 18GB |
| 라이선스 | MIT | 코드·가중치 CC BY-NC 4.0(비상업) |

### 2.2 맥에서의 설치 판정
엔진 화면의 카드는 이 맥을 검사해서 설치할 수 있는지 보여 줍니다.

| 상태 | 판정 |
|---|---|
| Apple Silicon, 메모리 32GB 이상 | 설치 가능 |
| Apple Silicon, 메모리 16~32GB | 설치 가능 + "권장(32GB)보다 적습니다" 경고 |
| Apple Silicon, 메모리 16GB 미만 | 설치할 수 없음 |
| 인텔 맥(소스로 실행한 경우. dmg는 arm64 전용이라 열리지 않음) | 설치할 수 없음 |
| YuE2 | 맥에서는 항상 설치할 수 없음 |
| 여유 공간 18GB 미만 | 설치할 수 없음(설치 위치를 바꾸면 됨) |

메모리 기준은 M1 Ultra 64GB에서 잰 값(최대 약 19GB 사용)을 바탕으로 정한 추정치입니다.

### 2.3 설치 위치
- 기본 위치는 `~/Library/Application Support/Road Music/`입니다.
- 엔진 화면의 `설치 위치 → 변경`으로 다른 디스크에 둘 수 있습니다. 고른 폴더 안에 `Road Music` 폴더가 생기고, 실행 환경과 모델이 모두 그곳에 들어갑니다.
- 위치는 **설치하기 전에** 바꾸세요. 설치하는 중에는 바꿀 수 없습니다.

### 2.4 다시 설치, 다시 받기
- **다시 설치**(설치된 엔진): 받아 둔 모델은 가능한 한 다시 쓰고, 빠진 파일만 받습니다. 인터넷이 끊겨 설치가 실패했을 때도 이 버튼을 씁니다.
- **다시 받기**: 설치는 됐는데 모델 파일이 없을 때 나옵니다. 빠진 파일만 받습니다.
- **엔진 없이 시작**: 엔진 없이 앱을 씁니다. 곡 불러오기, 듣기, 영상 만들기는 됩니다.

## 3. 곡 만들기

### 3.1 가사
- **구간 태그:** `[Verse]`(벌스), `[Pre-Chorus]`(프리코러스), `[Chorus]`(후렴), `[Bridge]`(브릿지)로 구간을 나누면 곡 구조가 좋아집니다. 알 수 없는 태그와 지시문은 자동으로 빠집니다.
- **구간 나누기:** 가사 덩어리마다 구간 태그를 붙입니다. 4줄 이상 붙여 넣으면 자동으로 붙습니다. 붙인 태그는 `⌘Z`로 되돌릴 수 있습니다.
- **가사 점검:** 박자가 밀리거나 발음이 뭉개질 수 있는 줄을 찾아 줍니다.
  - 가사 칸 아래에 `가사 점검 ✓` 또는 `가사 점검: 주의 n개`가 나옵니다.
  - 누르면 줄별 목록이 열리고, 항목을 누르면 그 줄로 이동합니다.
  - `숫자를 한글 읽기로 바꾸기`로 "2024"를 "이천이십사"로 바꿀 수 있습니다.
  - 점검은 안내일 뿐이라 그대로 만들어도 됩니다.
- **태그 안내:** 구간 태그 설명을 보여 줍니다.
- **가사 없이 (연주곡):** 가사 칸이 꺼지고, 보컬·허밍·합창이 나오지 않게 요청합니다. 프리셋도 연주곡용으로 바뀝니다.
- **곡 제목:** 비우면 `#` 제목 줄 → 첫 가사 줄 → `무제` 순서로 정해집니다.
- **✕ 지우기:** 제목과 가사를 지웁니다. 스타일과 시드는 남습니다.

작성 중인 가사와 스타일은 자동 저장되지 않습니다. 앱을 끄거나 언어를 바꾸면 사라집니다. 남겨 둘 조합은 `＋ 내 프리셋`으로 저장하세요.

### 3.2 스타일 · 장르
- **스타일 칸:** 장르, 분위기, 보컬 톤을 짧은 영어 단어로, 쉼표로 나눠 적으면 가장 잘 나옵니다.
  - 예: `bossa nova jazz, relaxed cafe mood, smooth female vocal`
- **프리셋 칩:** 보컬곡 11종, 연주곡 17종이 있습니다. 누르면 스타일 칸이 그 프리셋 문장으로 바뀝니다.
- **＋ 내 프리셋:** 지금의 스타일·악기·템포·구조를 이름 붙여 저장합니다.
  - 폴더로 묶을 수 있습니다(`📁`).
  - `✕`로 지웁니다.
- **시드:** 비우면 매번 다른 곡이 나옵니다. 같은 시드와 같은 입력이면 같은 곡이 나옵니다.

### 3.3 악기 · 템포 · 구조
- **악기(3칸):** 피아노, 기타, 드럼, 현악, 브라스, 신스 등 37종에서 고릅니다. 고른 악기가 스타일에 영어 태그로 더해집니다.
- **지정한 악기만 (엄격):** 고르지 않은 악기를 줄이도록 요청합니다. 켜면 `프롬프트 강하게` 옵션이 나옵니다. 이 옵션은 YuE2에만 적용되고 시간이 약 2배가 됩니다. ACE-Step에는 영향이 없습니다.
- **템포:** 40~220 BPM입니다. 비우면 자동입니다. ACE-Step에는 별도 BPM 값과 스타일 태그로, YuE2에는 스타일 태그로 전달합니다. 선택한 악기는 두 엔진 모두 스타일 프롬프트를 통해 요청하며 실제 소리를 완전히 고정하지는 않습니다.
- **구조:**
  - 5가지가 있습니다: 기본, 팝, 짧게, 주제와 변주, BGM 반복형.
  - 보컬곡은 가사 칸이 비어 있을 때 고르면 구간 틀을 넣어 줍니다. 노래의 실제 구조는 가사의 태그가 정합니다.
  - YuE2 연주곡에는 고른 구조가 섹션 태그로 전달됩니다. ACE-Step 연주곡은 현재 가사를 `[Instrumental]`로 대체하므로 선택한 구조가 반영되지 않습니다. BGM 반복형의 A·B·A·B 반복도 ACE-Step 연주곡에는 적용되지 않습니다.
- 빌더 아래의 `YuE2에 보낼 태그`에서 최종 스타일 문장을 미리 볼 수 있습니다. ACE-Step도 같은 문장을 씁니다.

### 3.4 고급 설정 (YuE2 전용)
작곡 방식, Temperature, Top-p/k, 반복 억제, CFG, 최대 길이, 악보 단계 설정, 합성 단계가 있습니다. ACE-Step을 고르면 흐려지고 접힙니다. 맥에서는 쓸 일이 없습니다.

### 3.5 아래 줄: 엔진 · 길이 · 한 번에
- **엔진:** 설치된 엔진만 고를 수 있습니다. 설치 안 된 엔진을 고르면 엔진 화면이 열립니다.
- **길이:**
  - `자동`이면 가사 양에 맞춰 엔진이 길이를 정합니다. 짧은 가사는 30초~1분 정도입니다.
  - 1·3·5·10·30초, 1·2·3·4·5·6분을 고를 수 있습니다.
  - `직접 입력`을 고르면 초 단위로 입력합니다 (소수 가능). ACE-Step은 1~600초, YuE2는 20~360초입니다. YuE2는 목표 길이에 가깝게 생성하며 실제 길이가 달라질 수 있습니다. 20초보다 짧은 음향은 ACE-Step을 사용합니다.
  - ACE-Step에서 10초 미만은 10초로 생성한 뒤 요청한 길이로 자르고 끝에 짧은 페이드를 적용합니다.
  - 4분 이상인데 가사가 짧으면 간주·솔로·아웃트로 구간을 덧붙입니다.
- **효과음 (실험):** ACE-Step으로 1~30초 음향을 만듭니다. 켜면 가사·악기·템포·구조 대신 `스타일 · 장르` 칸의 소리 설명을 사용합니다. 예: `short electronic notification chime, clear bright tone`. 음악 모델 기반이라 일반 효과음의 품질은 달라질 수 있습니다. 악보·커버·녹음과 함께 사용할 수 없습니다.
- CLI 예: `road-music song:generate --json '{"engine":"ace","soundEffect":true,"targetSeconds":3,"style":"short electronic notification chime"}'`
- **한 번에:** 1·2·3·4·6·8곡을 고릅니다. 시드만 다른 버전을 만들어 비교할 수 있습니다. 제목 뒤에 ` A`, ` B`…가 붙습니다.

### 3.6 진행 표시와 대기열
- 만드는 중인 곡은 가운데 목록 맨 위에 그라데이션 테두리 카드로 나옵니다. 단계 이름과 남은 시간이 표시됩니다.
- ACE-Step의 단계는 `모델 불러오는 중`(처음 한 번) → `곡 구성 짜는 중` → `노래 만드는 중` → `저장하고 가사 시각 맞추는 중`입니다.
- 만드는 중에 `곡 만들기`를 누르면 **대기열**에 들어갑니다. 한 번에 한 곡씩 만듭니다.
  - 대기 카드는 끌어서 순서를 바꾸고, `✕`로 뺍니다.
  - 목록 위 `일시정지`/`재개`, `대기열 비우기`
  - 실패한 곡은 빨간 카드로 남습니다. `↻`로 다시 시도합니다.
- 앱을 껐다 켜도 대기열이 남아 이어서 만듭니다.
- 만드는 중인 카드의 `✕`를 누르면 취소합니다. 지금 단계가 끝나는 대로 멈춥니다.
- 끝나면 "곡이 완성되었습니다 🎵"가 뜨고, 새 곡이 선택됩니다.

## 4. 커버, 녹음, 악보

### 4.1 커버 만들기
곡 상세의 `커버 만들기`를 누르면 그 곡을 바탕으로 다시 만듭니다.

- **소리 커버(ACE-Step, 맥에서 됨):** 원곡의 멜로디·리듬·구성을 바탕으로, 지금 적은 스타일·가사로 다시 만듭니다. 길이는 원곡과 같습니다.
  - `원곡 닮은 정도`: `많이 닮게`, `보통`(기본), `자유롭게`
  - 다른 곳에서 만든 곡을 `불러오기`한 뒤 커버할 수도 있습니다.
- **악보 커버(YuE2, 맥에서 안 됨):** 원곡의 악보를 그대로 두고 스타일·가사만 바꿉니다.
- 스타일 카드 위에 커버 바가 나오는 동안은 커버 모드입니다. `해제`를 누르면 새 곡 모드로 돌아갑니다.

### 4.2 녹음으로 곡 만들기 (ACE-Step)
허밍이나 기타·피아노 연주를 녹음하면, 그 멜로디·리듬·코드 흐름으로 곡을 만듭니다.

1. `녹음으로`를 누릅니다.
2. `● 녹음 시작` → `■ 녹음 멈추기`를 누릅니다. 최대 5분입니다. 녹음 파일이 있으면 `파일 고르기`로 고릅니다.
3. `곡 길이`를 고릅니다: `녹음 길이 그대로` 또는 약 1·2·3분. 녹음보다 길게 고르면 자연스럽게 이어 붙입니다.
4. `이 녹음으로 곡 만들기`를 누릅니다. 스타일을 적고, 가사를 적거나 연주곡을 고른 뒤 `곡 만들기`를 누릅니다.

**맥 마이크 권한:** 녹음 파일(`파일 고르기`)로 곡을 만드는 것은 맥에서 확인했습니다. 마이크로 직접 녹음하는 것은 아직 시험하지 않았고, 아래는 macOS의 일반 동작입니다.
- 처음 녹음할 때 macOS가 마이크 사용을 묻습니다. `허용`을 누릅니다.
- 거절했다면 `시스템 설정 → 개인정보 보호 및 보안 → 마이크`에서 `Road Music`을 켭니다. 소스로 실행할 때는 `Electron`이나 터미널 앱을 켭니다.
- 서명하지 않은(애드혹) dmg는 새로 빌드할 때마다 macOS가 다른 앱으로 보고 권한을 다시 물을 수 있습니다.
- 권한을 거절한 상태로 녹음하면 앱이 위 경로를 안내합니다(이 화면은 실제로 확인하지 않음).

### 4.3 악보 보기 · 악보 불러오기 · 악보만 (YuE2 전용)
YuE2가 쓴 ABC 악보를 보고 고쳐서 다시 만들거나, MIDI·ABC 악보를 불러와 멜로디로 쓰는 기능입니다. 맥에서는 YuE2를 설치할 수 없으므로 쓸 수 없습니다. ACE-Step을 고르면 `악보만`과 `악보 불러오기`가 꺼집니다.

## 5. 프로젝트와 곡 관리

### 5.1 프로젝트
- 곡은 프로젝트별 폴더에 모입니다. 기본 프로젝트는 `기본`입니다.
- `＋`로 새 프로젝트를 만들고, `✎`로 이름을 바꿉니다. 프로젝트 이름에 넣은 `\ / : * ? " < > | # %`는 자동으로 빠집니다.

### 5.2 곡 목록
- 목록 순서는 위에서부터 만드는 중인 곡, 대기 중인 곡, 실패한 곡, 완성곡입니다.
- 곡 카드를 끌어 순서를 바꿉니다. 앨범 내보내기와 영상이 이 순서를 따릅니다.
- `≡`(목록에서만 빼기): 파일은 그대로 두고 목록에서만 뺍니다. 맨 아래 `목록에서 뺀 곡`에서 다시 넣습니다.
- `🗑`(삭제): 곡 폴더를 휴지통으로 옮깁니다.
- `선택 삭제`: 여러 곡을 체크해 한꺼번에 휴지통으로 옮깁니다.
- **미완성 곡**(점선, 노란 글씨): 중간에 멈춘 곡입니다. 누르면 끝난 단계 다음부터 이어 만듭니다.
- `전체 듣기`: 목록 순서대로 미니 플레이어로 듣습니다.
- `전체 선택`·`전체 해제`: 현재 프로젝트의 완성된 음원만 한꺼번에 체크하거나 해제합니다. 미완성 곡·악보만 있는 곡은 제외하며, 선택은 프로젝트별로 기억합니다. 영상 스튜디오를 닫아도 체크박스를 사용할 수 있습니다.
- `선택 곡 저장`: 체크한 곡만 MP3(320kbps) 또는 WAV로 일괄 저장합니다. 형식·트랙 번호를 고른 뒤 저장 폴더를 선택합니다. 같은 제목은 번호를 붙여 구분하고 기존 파일과 원본 곡은 덮어쓰지 않습니다. WAV 원본을 지운 곡은 MP3에서 변환하므로 음질이 복원되지는 않습니다.

### 5.3 불러오기
`불러오기`로 다른 곳에서 만든 음악 파일을 지금 프로젝트에 넣습니다.
- 형식: MP3, WAV, FLAC, M4A, AAC, OGG, OPUS, WMA, AIFF, AIF
- 불러온 곡은 듣기, 영상 만들기, 소리 커버에 쓸 수 있습니다.
- 가사·스타일 정보가 없으므로 `설정 복제`와 `가사 SRT`는 꺼집니다.

### 5.4 곡 상세
곡 카드를 누르면 아래에 열립니다.

| 버튼 | 하는 일 |
|---|---|
| 설정 복제 | 그 곡의 가사·스타일·악기·시드·길이를 입력 칸에 되돌립니다. 시드를 비우면 같은 가사로 다른 곡이, 그대로 두면 같은 곡이 나옵니다 |
| 커버 만들기 | 4.1 참고 |
| 악보 보기 | YuE2 곡만 |
| ⤓ MP3 / ⤓ WAV | 원하는 곳에 저장(MP3는 320kbps) |
| ⤓ 가사 SRT | 가사 자막 저장. ACE-Step 곡은 노래하며 기록한 가사 시각을 씁니다 |
| 이름 변경, 폴더 열기, 삭제 | |

`곡 정보`를 펼치면 길이, 형식, 시드, 스타일, 가사, 만든 때, 걸린 시간, 엔진이 보입니다. `크게 보기`를 누르면 넓은 창에서 가사 전체를 보고 복사할 수 있습니다.

## 6. 설정 · 도구
가운데 열의 `설정 · 도구`를 펼치면 나옵니다.

| 항목 | 설명 |
|---|---|
| 완성되면 MP3로 자동 저장 | 곡이 끝나면 MP3(320kbps)를 함께 만듭니다 |
| 원본(WAV) 지워 용량 아끼기 | 자동 MP3를 켰을 때만 켤 수 있습니다. 용량이 약 1/10이 되지만 음질이 조금 줄어듭니다 |
| 앨범으로 내보내기 | 지금 프로젝트의 완성곡을 한 폴더에 모읍니다. 트랙 번호, 곡 제목, 앨범 이름 태그가 붙습니다. MP3(320kbps) 또는 WAV |
| 이미 만든 곡 정리 | 이미 만든 곡을 MP3로 바꾸고 WAV를 지웁니다 |
| 모델 위치 옮기기 | **YuE2 모델용입니다. 맥에서는 누르지 마세요.** YuE2가 쓰는 모델 저장소만 새 `RoadMusic-models` 폴더로 검증·복사해 옮깁니다. Hugging Face 캐시 전체나 다른 AI 도구의 모델은 옮기지 않습니다 |
| AI 엔진 (설치 · 사양 확인) | 엔진 화면을 엽니다 |
| 곡 저장 → 옮기기 | 곡 라이브러리 전체를 다른 폴더로 옮깁니다. 만드는 중이거나 대기열이 있으면 옮길 수 없습니다 |
| 내보내기 → 변경 | MP3·WAV·앨범을 저장할 때 처음 열리는 폴더를 정합니다 |

## 7. 듣기 (미니 플레이어)
- 곡 카드의 `▶`나 `전체 듣기`로 열립니다. 위쪽을 끌어 옮길 수 있습니다.
- `⏮` `⏯` `⏭`로 조작합니다. 곡이 끝나면 다음 곡으로 넘어갑니다.
- **가사 따라가기:**
  - ACE-Step 곡은 노래하며 기록한 시각으로 가사를 맞춥니다.
  - 가사 줄을 누르면 그 위치부터 재생합니다.
  - 손으로 스크롤하면 4초 동안 자동 따라가기가 멈춥니다.
- 미니 플레이어를 재생하면 영상 미리보기는 멈춥니다. 반대도 같습니다.

## 8. 영상 만들기
오른쪽 열에서 곡을 스펙트럼 영상(MP4, H.264 + AAC 320kbps)으로 만듭니다.

### 8.1 곡 고르기와 미리보기 준비
- **넣을 곡** 선택:
  - `선택한 곡`: 지금 누른 곡 1개
  - `체크한 곡 (목록 순서)`: 곡 카드 앞 체크박스로 고른 곡. 체크하면 자동으로 이 모드가 됩니다.
  - `프로젝트 전체 (목록 순서)`
- `미리보기 준비`를 누르면 음원을 하나로 합치고 스펙트럼을 분석합니다. 결과는 캐시에 남아 다음에는 빨리 끝납니다.
- 준비가 끝나면 `▶`와 재생바로 미리 볼 수 있습니다. 미리보기와 최종 영상은 같은 분석 데이터를 씁니다.
- 준비한 뒤 곡 선택을 바꾸면 `미리보기 준비`를 다시 누르라는 안내가 나옵니다. 막대 수와 fps는 바꾸면 자동으로 다시 분석합니다.

### 8.2 영상 제작 옵션

| 항목 | 선택지 | 기본 |
|---|---|---|
| 배경 | 이미지 / 영상 / 없음(그라데이션) | 없음 |
| 배경 어둡게 | 0~100% | 25% |
| 영상 길이 | 1회(곡 길이 그대로) / 반복 횟수(1~1000회) / 시간(최대 10시간, 루프) | 1회 |
| 출력 화질 | 720p, 1080p, 1440p, 2160p(4K) | 1080p |
| fps | 30 / 60 | 30 |
| 렌더링 | GPU / CPU | GPU |

맥에서는 GPU 항목이 `GPU (Apple)`로 나오고 맥 GPU(VideoToolbox)로 인코딩합니다. Windows에서는 `GPU (NVIDIA)`(NVENC)입니다. M1 Ultra에서 1080p30 영상 1분 분량을 만드는 데 GPU는 약 23초, CPU는 약 27초 걸렸습니다. 앱 안에서 렌더해 본 것은 1080p30뿐입니다. GPU 렌더가 실패하면 앱이 `CPU`로 바꿔 두니 다시 누르면 됩니다.

### 8.3 스펙트럼
섹션 제목 오른쪽 스위치로 켜고 끕니다.

| 항목 | 선택지 | 기본 |
|---|---|---|
| 모양 | 막대, 미러 막대, 선형 파형, 원형 | 막대 |
| 좌우 대칭 | 좌(저음 왼쪽), 중앙(대칭), 우(저음 오른쪽) | 중앙 |
| 막대 수 | 8~128 | 64 |
| 위치 | 하단, 중앙, 직접 배치(편집 모드에서 옮기면 자동) | 하단 |
| 높이, 너비 | 화면 비율 | 0.3, 0.82 |
| 색상 | 아래쪽 색, 위쪽 색(그라데이션) | 보라 → 분홍 |
| 글로우 | 0~1 | 0.5 |
| 진폭 | ×0.3~×3 | ×1.0 |

### 8.4 이퀄라이저 (EQ)
- 7밴드입니다: 60, 150, 400, 1k, 3k, 8k, 16k Hz. 각 밴드는 ±10dB입니다.
- 프리셋은 8가지입니다: 플랫, 저음 강조, 보컬 강조, 고음 강조, 따뜻하게, 선명하게, 댄스, 로파이. 밴드를 손으로 움직이면 `사용자 설정`이 됩니다.
- 밴드를 끌거나 키보드로 조절하고, 두 번 누르면 0dB가 됩니다.
- EQ는 소리와 스펙트럼, 미리보기와 최종 영상에 함께 적용됩니다. 끄면 원음 그대로 나갑니다.

### 8.5 곡별 배경
- 영상 스튜디오가 열려 있으면 곡 카드에 작은 네모 칸이 생깁니다. 누르면 그 곡 전용 이미지나 영상을 넣을 수 있습니다.
- 플레이리스트 영상에서 그 곡이 나오는 동안 이 배경이 보입니다. 넣지 않은 곡은 스튜디오 배경을 씁니다.
- 같은 배경이 이어지는 곡들은 배경 영상이 끊기지 않고 이어집니다.

### 8.6 편집 모드
`✎ 편집 모드로 영상 만들기`를 누르면 큰 화면 편집기가 열립니다.

- **왼쪽(에셋):**
  - `+ 이미지 불러오기`로 로고 같은 이미지를 넣습니다. 미리보기로 끌어다 놓거나 두 번 누르면 붙습니다. 배경이 투명한 PNG가 좋습니다.
  - **트랙리스트:** 곡 목록을 화면에 띄우고, 지금 곡을 강조합니다. 곡이 12개를 넘으면 목록이 넘어갑니다.
- **가운데(미리보기):**
  - 스펙트럼, 트랙리스트, 이미지를 눌러 고릅니다.
  - 끌어서 옮기고, 모서리로 크기를 바꾸고, 휠로 확대·축소합니다.
  - 가운데로 가면 안내선에 붙습니다.
- **오른쪽(속성):** 위치, 크기, 투명도, 보이는 시간(시작·끝 초), 겹침 순서, 트랙리스트 제목과 색을 숫자로 맞춥니다.
- **아래(타임라인):**
  - 곡, 배경, 트랙리스트, 이미지가 줄별로 보입니다.
  - 이미지 클립은 끌어서 시간을 옮기고, 양끝을 끌어 길이를 줄입니다.
- 위쪽 `전체화면`으로 넓게 쓰고, `영상 만들기`로 바로 렌더합니다.

### 8.7 렌더와 결과
1. `영상 만들기`를 누르면 저장할 파일 이름을 묻습니다.
   - 프로젝트 전체를 고른 경우 기본 이름은 `<프로젝트> 플레이리스트`입니다.
   - 그 밖에는 첫 곡 제목입니다.
2. 진행 막대에 프레임 수, 속도, 남은 시간이 나옵니다.
   - `취소`를 누르면 만들던 파일을 지웁니다.
   - 렌더 중에는 맥이 잠자기에 들지 않습니다.
3. 결과:
   - 경로가 나오고, `폴더 열기`와 `타임스탬프 복사`를 쓸 수 있습니다. 타임스탬프는 유튜브 설명란의 챕터 목록입니다.
   - **미리보기 일치도(SSIM):** 미리보기와 최종 영상의 몇 프레임을 비교합니다. 1에 가까울수록 같습니다. 곡별 배경, 붙인 이미지, 영상 배경이 있으면 이 검사는 건너뜁니다.

| 키 | 용도 | 예 |
|---|---|---|
| `ffmpeg` | ffmpeg가 Homebrew 위치(`/opt/homebrew/bin`, `/usr/local/bin`)나 PATH에 없을 때 경로 지정 | `"/Users/me/bin/ffmpeg"` |
| `songsDir` | 곡 라이브러리 위치. 보통은 `곡 저장 → 옮기기`를 쓰세요 | `"/Volumes/Music/Road Music Songs"` |
| `dataDir` | 엔진·실행 환경 위치. 보통은 엔진 화면의 `변경`을 쓰세요 | `"/Volumes/SSD/Road Music"` |
| `pythonPath` | YuE2용 파이썬을 직접 지정(개발용) | |
| `hfHome` | YuE2 모델 캐시 위치 | |

ffmpeg는 다음 순서로 찾습니다: 앱에 들어 있는 ffmpeg(Windows 빌드만, 소스 실행이면 `vendor/ffmpeg/`) → `settings.json`의 `ffmpeg` → `/opt/homebrew/bin/ffmpeg` → `/usr/local/bin/ffmpeg` → PATH.

## 13. 문제 해결
먼저 `~/Library/Application Support/Road Music/app.log`의 마지막 부분을 봅니다. 곡 생성 오류 창의 `기록 파일 열기`로도 열 수 있습니다.

| 증상 | 원인과 해결 |
|---|---|
| ACE-Step 카드가 "설치할 수 없음" | 인텔 맥이거나 메모리가 16GB 미만이거나, 여유 공간이 18GB 미만입니다. 공간 문제면 `설치 위치 → 변경`으로 다른 디스크를 고르세요 |
| 설치 중 "AI 엔진 설치" 단계 실패 | 인터넷 끊김, 또는 macOS 13 이하(MLX는 14 이상 필요)입니다. 연결을 확인하고 `다시 설치`를 누르세요 |
| "맥의 GPU(Metal)를 인식하지 못했습니다" | macOS를 최신으로 올리고 `다시 설치`를 누르세요 |
| 첫 곡이 오래 걸림 | 처음 한 번은 모델을 불러오느라 1~3분 더 걸립니다. 다음 곡부터는 빠릅니다 |
| 곡 생성 중 멈추거나 메모리 부족 | 다른 앱을 닫고, `길이`를 짧게, `한 번에`를 1곡으로 둡니다. 16~32GB 맥은 아직 실측하지 않았습니다 |
| "ffmpeg를 찾지 못했습니다" 류 오류 | `brew install ffmpeg`. 다른 위치면 `settings.json`에 `ffmpeg` 경로를 넣으세요 |
| "GPU(Apple VideoToolbox)로 인코딩하지 못했습니다" | 앱이 `렌더링`을 `CPU`로 바꿔 둡니다. 다시 `영상 만들기`를 누르세요. 매번 이렇다면 인텔용 ffmpeg(`/usr/local/bin/ffmpeg`)를 쓰고 있을 수 있습니다. `brew install ffmpeg`로 Apple Silicon용을 설치하세요 |
| 녹음이 안 됨 | `시스템 설정 → 개인정보 보호 및 보안 → 마이크`에서 Road Music을 켜세요 |
| 앱이 "확인할 수 없습니다"라며 안 열림 | [시작하기 2.3](getting-started.md#23-처음-열-때-나오는-경고) |
| `악보만`, `악보 불러오기`가 꺼져 있음 | YuE2 전용 기능입니다. 맥에서는 쓸 수 없습니다 |
| 강제 종료 뒤 메모리가 계속 쓰임 | 엔진 프로세스가 남았을 수 있습니다. `활성 상태 보기`에서 `python`을 찾아 끝내거나, 터미널에서 `pkill -f ace_worker.py`를 실행하세요. 앱을 `⌘Q`로 끄면 함께 끝납니다 |

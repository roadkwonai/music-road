# 리서치 기반 음악 만들기

최근 차트·플레이리스트를 조사하고, 근거를 음악적 특징으로 해석한 뒤 창작 가사와 Road Music 옵션으로 바꾸는 요청 모음이다. [장르별 프롬프트](genre-prompts.md)는 바로 제작할 때, [옵션 가이드](music-options.md)는 입력을 세밀하게 지정할 때 사용한다.

**자료 확인일: 2026-10-15 KST.** 아래 참고 근거는 주로 2025년 결산과 2026년에 발표된 2025년 통계다. 2026년 10월의 실시간 인기 순위가 아니다. 실제 “요즘” 요청은 실행일 기준으로 다시 조사한다.

## 짧게 요청하기

프로젝트 안에서 실행하는 AI에게 복사해서 전달한다. 다른 프로젝트라면 먼저 설치 폴더의 절대 경로에 있는 [AGENTS.md](../AGENTS.md)를 읽도록 한다.

```text
AGENTS.md와 docs/music-research.md를 따라 최근 인기 있는 AI 음악 플레이리스트 스타일을
조사해 하나 골라줘. 창작 한국어 가사와 생성 프롬프트를 만들고 CLI로 1곡 생성한 뒤
여기서 들을 수 있게 가져와줘.
```

```text
최근 한국 음악 흐름을 조사해서 K-POP·트로트·애절한 락발라드를 한국어 가사로 각각 1곡씩 만들어줘.
AGENTS.md와 docs/music-research.md를 따르고, 근거·가사·적용 옵션·완료 음원을 함께 보여줘.
```

```text
AGENTS.md와 docs/music-research.md를 따라 여성 보컬의 락발라드와 애절한 발라드를 각각 1곡 만들어줘.
한국어 창작 가사, 150초 안팎으로 만들고 두 장르의 편곡 차이가 잘 들리게 해줘.
```

첫 요청은 리서치와 생성까지의 작업을 포함하되, [기본 검토 규칙](music-review.md)에 따라 먼저 가사·프롬프트를 검토받는다. “가사와 프롬프트까지 모두 자동으로 정하고 검토 없이 생성해줘”를 덧붙이면 자체 검증 후 자동 생성하고 근거 자료를 제공한다. 조사·가사·설정까지만 원하면 “생성은 실행하지 말고 조사와 가사·옵션만 제안해줘”를 덧붙인다. 문서 예시를 읽는 것만으로 생성 요청을 실행하지 않는다.

## 조사에서 생성까지

| 단계 | AI가 할 일 | 남길 결과 |
| --- | --- | --- |
| 1. 범위 정하기 | 실행일 기준 최근 30~90일, 한국/글로벌, 청취 목적 구분 | 기준일·지역·기간·대상 |
| 2. 근거 수집 | 공식 차트·플랫폼 자료와 공개 플레이리스트 사례 확인 | URL·게시일/집계일·조회 시각·지표 |
| 3. 후보 비교 | 3개 방향의 음악적 특징과 근거 수준 비교 | 확인 사실·해석·한계·선택 이유 |
| 4. 창작 | 가사·보컬·악기·리듬·곡 전개 설계 | 독창적인 가사와 짧은 스타일 태그 |
| 5. 옵션 변환 | ACE는 [공식 가이드 적용 절차](ace-prompt-guide.md)를 읽고 실행 버전 schema와 설치 엔진에 맞추기 | `song:generate` JSON·최종 입력 길이·옵션 선택 이유 |
| 6. 요청자 검토 | 가사·최종 프롬프트·JSON·출처를 제시하고 승인 대기. 전체 자동 위임이면 생략 | 승인한 안 또는 자동 위임 범위 |
| 7. 생성·검증 | 작업 완료 대기, 파일·길이 확인, 가능하면 청취 | 실제 파일·가사·옵션·사용 근거·평가 한계 |

차트의 곡 순위는 특정 BPM·보컬·편곡이 성공 원인이라는 인과 증거가 아니다. “이 자료를 보고 이런 제작 방향을 선택했다”와 “이 설정이 통계적으로 최적이다”를 구분한다.

### 조사할 때 확인할 것

- **차트:** 플랫폼·국가·집계 기간·곡 단위 여부를 적는다. 서로 다른 차트의 순위를 하나로 합산하지 않는다.
- **플레이리스트:** 영상/채널 URL, 제목, 업로드일, 영상 길이, 확인 시점의 조회수, AI 사용 명시 여부를 적는다.
- **비교:** 오래된 긴 영상의 누적 조회수와 어제 올린 짧은 영상의 조회수를 같은 조건처럼 비교하지 않는다. 일평균 조회수도 대략적인 보조 지표이며 실제 유지율은 아니다.
- **AI 표기:** 제목·설명·제작자 공개 내용으로 AI 사용을 확인한다. 표기가 없으면 “미확인”으로 남긴다. 외관·음색만으로 AI 음악이라고 판정하지 않는다.
- **음악 분석:** 직접 들었는지, 메타데이터·제작자 설명만 읽었는지 밝힌다. 듣지 않았다면 정확한 BPM·조성·보컬 특성을 측정했다고 쓰지 않는다.
- **자료 부족:** 최근 자료가 없거나 접근할 수 없으면 확인 가능한 기간을 밝힌다. 오래된 자료를 “현재 1위”로 바꾸지 않는다.

Spotify의 **AI Playlist**는 프롬프트에 따라 기존 곡을 추천·선곡하는 기능이다. AI가 새로 만든 음원으로 구성한 영상 플레이리스트의 인기 지표와는 다르다. [Spotify 기능 안내, 2025-04-24](https://newsroom.spotify.com/2025-04-24/spotify-expands-ai-playlist-in-beta-to-premium-listeners-in-40-new-markets/)

트로트·여성 락발라드·카페 재즈·로파이는 [장르 레시피](genre-prompts.md)에서 취향별 예시로 제공한다. 위 자료만으로 이 장르들의 최신 인기 순위를 정하지 않는다. **특정 AI 생성음악 플레이리스트의 현재 인기는 이 참고 조사에서 검증하지 않았다.** 아래 프롬프트는 실행 시 그 부분까지 조사하도록 구성했다.

## 상황별 상세 프롬프트

### 1. 최근 AI 플레이리스트 스타일 하나를 골라 1곡 생성

```text
AGENTS.md와 docs/music-research.md를 따라 오늘 기준 최근 90일의 한국 음악 차트와
유튜브 AI 생성음악 플레이리스트 사례를 조사해 제작 방향 3개를 비교하고 하나를 골라줘.

각 자료의 URL·게시일/집계 기간·지역·지표를 기록해줘.
플레이리스트는 업로드일·길이·확인 시점 조회수·제작자의 AI 사용 표기를 확인하고,
직접 청취한 분석과 설명문에서 얻은 정보를 구분해줘.
인기라는 근거가 약하면 한계를 밝히고 내 취향에 맞는 대안으로 골라줘.

선정 방향으로 한국어 창작 가사, 보컬·악기·BPM·구성의 선택 이유,
짧은 쉼표 태그의 style과 실행 가능한 song:generate JSON을 작성해줘.
설치된 엔진으로 120~180초 범위의 곡 1개를 생성하고 완료를 확인해줘.
제목·가사·조사 근거·최종 옵션·실제 오디오 경로를 보여주고,
채팅에서 오디오 첨부가 지원되면 바로 들을 수 있게 가져와줘.
```

### 2. K-POP·트로트·애절한 락발라드 각 1곡

```text
AGENTS.md와 docs/genre-prompts.md, docs/music-research.md를 따라 3곡을 만들어줘.
오늘 기준 최근 90일의 한국 음악 흐름과 장르별 자료를 조사하되,
최신 근거가 없는 장르는 유행을 단정하지 말고 장르 특성에 맞춰 제작해줘.

1) K-POP: 한국어 여성 보컬, 120초, 124 BPM 출발점,
   선명한 신스·베이스·드럼, 일상에서 다시 자신감을 찾는 독창적인 후렴.
2) 트로트: 한국어 남성 보컬, 150초, 126 BPM 출발점,
   아코디언·색소폰·셔플 리듬, 웃음과 그리움이 함께 있는 생활형 가사.
3) 애절한 락발라드: 한국어 남성 록 보컬, 180초, 72 BPM 출발점,
   피아노로 시작해 기타·드럼이 커지는 편곡, 마지막 인사를 주제로 한 가사.

최근 자료가 다른 설정을 제안하면 BPM·편곡은 근거를 설명하고 조정해줘.
각 곡의 가사·style·옵션은 별개로 만들고 장르 차이가 들리게 해줘.
3개의 별도 생성 요청을 순차 제출하고 각각 완료를 확인해줘.
최종 오디오·실제 경로·적용 옵션·출처를 곡별로 정리해줘.
```

### 3. 여성 락발라드와 여성 애절한 발라드 각 1곡

```text
AGENTS.md와 docs/genre-prompts.md를 따라 한국어 창작 가사의 여성 보컬 2곡을 만들어줘.
최근 여성 보컬 중심 음악 자료를 조사하되 실제 인물의 목소리나 기존 곡을 재현하지 마.

락발라드: 150초, 74 BPM, 담담한 첫 절과 힘 있는 마지막 후렴,
피아노·일렉기타·드럼 중심, 헤어진 뒤 자기 삶으로 돌아오는 이야기.
애절한 발라드: 150초, 66 BPM, 가까이 속삭이는 듯한 절제된 음색,
피아노·첼로·스트링 중심, 보내지 못한 편지를 접는 이야기.

각각 새로운 가사를 쓰고 벌스·후렴·브리지를 직접 구성해줘.
보컬 성별·음색은 style 요청임을 반영하고, 실제 결과를 확인할 수 있게 음원을 가져와줘.
각 곡 완료 후 실제 파일 경로와 최종 옵션을 제공해줘.
```

### 4. 카페용 플레이리스트 5곡 설계와 생성

```text
AGENTS.md와 docs/music-research.md를 따라 카페에서 오래 듣기 좋은 음악 사례를 조사해줘.
AI 생성음악임을 확인한 사례와 일반 플레이리스트를 구분해줘.

주악기는 따뜻한 피아노·기타·베이스 중심, 가사 없는 연주곡으로 5곡을 만들어줘.
곡마다 120초, BPM은 76~96 안에서 시작하고 조용한 재즈·어쿠스틱·로파이를 섞어줘.
같은 음색 계열을 유지하되 주악기·리듬·멜로디 분위기는 곡마다 다르게 설계해줘.
먼저 5곡의 제목·스타일·BPM·악기·길이 표를 만들고 이어서 CLI로 순차 생성해줘.
완료 곡만 모아 MP3 파일과 곡 순서를 제공해줘. 영상 제작·업로드는 포함하지 마.
```

### 5. 자료를 먼저 검토하고 나중에 생성

```text
AGENTS.md와 docs/music-research.md를 따라 최근 90일의 한국 보컬곡 흐름을 조사해줘.
공식 자료와 공개 플레이리스트 사례를 바탕으로 3개 제작 방향을 비교하고,
방향별 제목·한국어 창작 후렴·보컬·BPM·악기·길이·style 태그·CLI JSON을 제안해줘.
자료의 사실과 음악적 해석을 구분하고 링크와 날짜를 적어줘.
지금은 곡 생성·모델 다운로드를 실행하지 마.
```

### 6. 사용자가 고른 플레이리스트를 분석

```text
이 플레이리스트를 참고해 새 곡 1개를 만들어줘: [사용자가 고른 실제 URL]
AGENTS.md와 docs/music-research.md를 따라 공개된 제목·설명·트랙 정보를 확인하고,
접근 가능하면 대표 구간을 청취해 장르·악기·보컬·곡 전개를 분석해줘.
청취 불가나 BPM 측정 불가 항목은 추정/미확인으로 표시해줘.
한국어 창작 가사, 150초, 원곡을 복제하지 않는 독립적인 멜로디와 편곡으로 설계하고
설치된 CLI로 생성 완료까지 확인한 뒤 여기서 들을 수 있게 가져와줘.
```

## 분석을 가사와 옵션으로 바꾸기

“데이터 기반”은 조회수를 복사해서 프롬프트에 넣는 것이 아니다. 자료로 제작 방향을 고르고, 음악적 해석을 짧은 태그·가사·옵션으로 분리하는 것이다.

| 분석 결과 | 창작 지시 | Road Music 입력 |
| --- | --- | --- |
| 특정 기간 보컬곡 사례가 눈에 띔 | 감정을 전달하는 후렴을 중심에 배치 | 한국어 `lyrics`와 `style`의 보컬·감정 태그 |
| 휴식·집중용 긴 영상 사례 | 갑작스러운 전환을 줄인 연주곡 | `instrumental:true`, `parts.structure:"loop"` |
| UK garage 관련 플랫폼 관찰 | 스윙 리듬·짧은 보컬 훅으로 실험 | `style`의 짧은 리듬 태그, `parts.bpm` |
| 특정 플레이리스트 설명에 피아노 중심이라고 명시 | 피아노 중심 편성으로 새 곡 설계 | `parts.instruments:["piano", ...]`, 최대 3개 |
| 여성 보컬을 사용자가 선호 | 새 여성 리드 보컬로 요청 | `style`의 `female vocal`. 별도 보컬 성별 필드는 없음 |

### 창작 가사와 스타일 예시

다음은 위 근거 중 보컬 중심 제작 방향을 참고한 **창작 예시**다. 최신 1위 스타일을 재현한 결과가 아니며, 아래 가사로 실제 음원을 생성·청취하지 않았다.

| 항목 | 설정 |
| --- | --- |
| 장르 | 한국어 여성 락발라드 |
| 주제 | 이별 이후 자기 삶으로 돌아오기 |
| 길이·템포 | 150초·72 BPM 출발점 |
| 주악기 | `piano`, `electric guitar`, `drums` |
| 다이내믹 | 작은 첫 절 → 첫 후렴 → 브리지 → 넓게 펼쳐지는 마지막 후렴 |
| 스타일 | `Korean rock ballad, female rock vocal, restrained verse, soaring chorus, melodic guitar, warm piano, wide dynamics` |

```text
[Verse]
네가 놓고 간 우산을 접고
오래 비워 둔 창문을 열어
빛이 드는 작은 식탁 위에
내 이름으로 아침을 놓아

[Chorus]
이젠 나를 데리고 갈게
너를 기다리던 저 문을 지나
울다 멈춘 어제의 끝에서
오늘의 나를 불러 줄게

[Verse]
함께 걷던 길을 돌아와도
다른 꽃이 피는 계절이 와
못다 한 말 적힌 종이 위로
나를 위한 안녕을 덧써

[Chorus]
이젠 나를 데리고 갈게
너를 기다리던 저 문을 지나
울다 멈춘 어제의 끝에서
오늘의 나를 불러 줄게

[Bridge]
사랑했던 날을 지우진 않아
그 안에 나를 두고 오진 않아

[Chorus]
이젠 나를 데리고 갈게
아직 떨리는 마음을 안고서
끝이라 부른 그 자리 너머
새로운 나를 만나러 갈게
```

음악 프롬프트에는 태그만, 가사에는 부를 말과 섹션만 담는다. `parts.structure:"pop"`만 넣고 가사가 자동으로 위 순서로 재배열되길 기대하면 안 된다. 보컬곡 구성은 가사에 직접 적는다.

## 결과 보고와 청취 점검

최종 보고는 다음 항목을 짧게 묶는다.

1. **선택 근거:** 출처 링크·자료 기간과 실제 확인한 사실.
2. **창작 결과:** 제목·전체 가사·style·최종 CLI JSON·기록 가능한 seed.
3. **완료 증거:** 작업 결과, 실제 오디오 파일, 길이·포맷 확인.
4. **청취 결과:** 발음·후렴·보컬·악기·잘림을 실제 확인했는지와 남은 한계.

“여기서 바로 듣기”는 채팅 앱이 로컬 오디오 첨부를 지원할 때 제공한다. 지원하지 않으면 실제 파일 링크와 경로를 제공한다. 앱의 `player:play`는 로컬 재생이며 채팅 첨부와 별개다.

모든 조사에서 모든 후보를 직접 들을 수 있는 것은 아니다. 청취하지 않았다면 음질 평가를 만들어내지 않는다. 브라우저·플랫폼 접근 제한이 있어도 추정 결과를 실제 차트 수치로 채우지 않는다. 생성 작업의 재시도·파일 보존·설치 범위는 [공통 지침](../AGENTS.md)을 따른다.

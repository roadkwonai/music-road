# Road Music 1.4.0

앱과 AI CLI에서 GitHub 최신 버전을 확인하고 업데이트할 수 있습니다. README 첫 부분의 프롬프트를 복사하면 AI에게 CLI·음악 엔진 설치와 첫 곡 검증을 맡길 수 있습니다.

## 달라진 점

- 앱·CLI 서비스 시작 시와 15분마다 최신 정식 Release를 확인합니다. 새 버전은 앱 우측 상단에서 알립니다.
- 앱 버튼 또는 `update:install`로 다운로드·검증·설치·재시작을 진행합니다. CLI에는 업데이트 상태 조회·다운로드·알림 대기 명령도 제공합니다.
- SHA-256과 파일 크기를 검사하고, 설치 시 진행·대기 작업과 로컬 수정을 보호합니다. 기존 곡·엔진·설정은 유지합니다.
- 버전 태그를 push하면 테스트·DMG/CLI 키트 빌드·체크섬 확인 후 GitHub Release에 게시하는 워크플로를 추가했습니다.

## 설치와 이전

Apple Silicon 맥에서는 DMG의 `Road Music.app`을 Applications로 복사합니다. **1.3.1 사용자는 이 버전으로 최초 1회 직접 교체**해야 GitHub 업데이트 기능을 사용할 수 있습니다.

CLI 신규 설치는 [README의 AI 설치 프롬프트](https://github.com/roadkwonai/music-road#ai에게-설치-맡기기)를 사용하세요. Node.js 24와 `npm ci --include=dev`가 필요하며 음악 생성 엔진·ffmpeg는 별도로 준비합니다. 자동 CLI 소스 업데이트에는 수정 없는 공식 Git 체크아웃이 필요합니다.

## 지원 범위

macOS에서 테스트 119개, CLI 음원·자막 내보내기 및 CPU/GPU 영상 렌더 검증을 통과했습니다. 임시 1.3.1 설치본을 실제 1.4.0 DMG로 교체하고 재시작·곡·모델·설정 보존과 이전 앱 백업을 확인했습니다.

배포 GUI와 앱 자동 교체 대상은 macOS Apple Silicon입니다. Windows/Linux·Intel Mac 설치 파일은 이번 Release에 포함하지 않습니다. 앱은 애드혹 서명이며 Apple 공증이 없어 macOS에서 경고하거나 실행을 차단할 수 있습니다. 관리자 권한 상승이나 보안 정책 해제는 수행하지 않습니다.

상세 동작·실패 복구·CLI 사용은 [업데이트 가이드](https://github.com/roadkwonai/music-road/blob/v1.4.0/docs/updates.md)를 참고하세요. `SHA256SUMS.txt`에는 DMG와 CLI ZIP의 SHA-256이 들어 있습니다.

# Road Music 1.4.1

GUI와 CLI의 업데이트 알림부터 새 버전 재실행까지 확인하는 실제 설치 검증 도구를 추가했습니다. 음악 생성 엔진과 업데이트 실행 코드는 1.4.0과 같습니다.

- `scripts/verify-update-e2e.js`: 분리된 1.4.0 설치본에서 실제 GitHub 최신 Release를 확인하고, GUI 버튼 또는 CLI 명령으로 설치·재실행·데이터 보존·업데이트 후 음원 내보내기를 검사합니다.
- 상태 조회의 잘못된 제한 시간과 연결 실패를 구분해 테스트가 인수 오류를 숨기지 않도록 했습니다.
- 서비스 시작 시 확인과 15분 주기 알림의 회귀 검증을 추가했습니다.

이 Release를 실제 1.4.0 → 1.4.1 업데이트 검증 대상으로 사용합니다. 실행 결과는 [업데이트 전 과정 검증 보고서](https://github.com/roadkwonai/music-road/blob/main/docs/update-e2e-report.md)에 기록합니다.

Apple Silicon macOS 앱과 CLI 키트를 제공합니다. 앱은 애드혹 서명이며 Apple 공증이 없어 다른 Mac에서 보안 경고가 나타날 수 있습니다. Windows 자동 설치와 비-Git ZIP 키트의 자동 소스 교체는 지원하지 않습니다.

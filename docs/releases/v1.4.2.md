# Road Music 1.4.2

Git 소스 업데이트의 실패 복구를 수정했습니다. GitHub의 주석 태그를 실제 커밋으로 해석해, 새 버전 시작이 실패할 때 이전 소스와 의존성을 복구합니다. 오류 뒤 이전 앱의 중복 재시작도 제거했습니다.

GUI·CLI 알림부터 다운로드, 검증, 설치, 새 앱 재실행과 곡·모델·설정 보존까지 확인하는 검증 도구를 제공합니다. 자세한 실행 결과와 재현 방법은 [전 과정 검증 보고서](https://github.com/roadkwonai/music-road/blob/main/docs/update-e2e-report.md)에 기록합니다.

## 이전 버전의 도우미

설치는 업데이트를 시작하는 앱에 포함된 도우미가 담당합니다. 이미 설치된 **1.4.0·1.4.1 Git 소스판의 도우미**는 위 복구 수정을 포함하지 않습니다. 해당 버전에서 새 앱 시작이 실패했다면 최신 소스·의존성을 수동으로 복구하거나 최신 DMG를 설치해야 합니다. 곡·모델·설정은 별도 데이터 폴더에 유지됩니다. 수정된 소스 복구 도우미는 1.4.2부터 사용합니다.

Apple Silicon macOS용 앱은 애드혹 서명이며 Apple 공증을 받지 않았습니다. 다른 Mac의 Gatekeeper·권한 정책에 따라 실행이 차단될 수 있습니다. Windows 자동 설치와 비-Git ZIP 키트의 자동 소스 교체는 지원하지 않습니다.

# Road Music 1.4.3

업데이트 뒤 새 앱이 실제로 준비됐는지 확인하도록 설치 도우미를 수정했습니다. 새 프로세스가 잠시 살아 있는 것만으로 성공을 표시하지 않고, 공개 CLI의 실행 PID·목표 버전 응답과 1.5초의 준비 상태 유지를 확인합니다. 45초 안에 준비되지 않거나 바로 종료되면 이전 앱 복원을 시도하며, 안전한 복구가 불가능하면 수동 복구 필요 여부와 원인을 기록합니다.

실제 서명된 실패 후보 DMG에서 기존 앱 복원·단일 재시작·CLI 응답·설정과 곡·모델 폴더 보존을 확인했습니다. 실제 Git·npm을 사용하는 정상 설치와 시작 실패 복구 시험, 전체 회귀 테스트 121개도 통과했습니다. GUI·CLI 알림부터 새 앱 실행과 MP3 내보내기까지의 자세한 실행 결과는 [업데이트 검증 보고서](https://github.com/roadkwonai/music-road/blob/main/docs/update-e2e-report.md)를 참고하세요.

## 이전 버전과 호환성

도우미는 업데이트를 시작하는 앱에 포함됩니다. 이번 수정은 과거 설치본의 도우미에 소급 적용되지 않으므로 최신 DMG를 설치하거나 정상 업데이트를 완료한 뒤부터 사용합니다. 설치 결과는 `installerResult.ok`뿐 아니라 이번 목표 버전·새 PID도 확인하세요. 새 도우미는 `appReady: true`를 기록합니다. 사용법과 과거 도우미의 복구 제한은 [업데이트 가이드](https://github.com/roadkwonai/music-road/blob/main/docs/updates.md)에 정리했습니다.

Apple Silicon macOS에서 검증했습니다. 앱은 애드혹 서명이며 Apple 공증을 받지 않아 다른 Mac의 Gatekeeper 정책에 따라 차단될 수 있습니다. Windows 자동 설치와 비-Git ZIP 소스 자동 교체는 지원하지 않으며 Linux의 실제 실행은 검증하지 않았습니다.

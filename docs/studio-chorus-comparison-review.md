# 원본/v3 후렴 비교 검수와 HTML A/B (2026-10-20)

추가 음원 생성 없이 기존 두 녹음을 비교했다. **이 세션에는 소리를 지각하는 청취 입력 도구가 없어 직접 청취 판정은 수행하지 못했다.** 오디오 재생·표시·전사·측정은 직접 청취와 구분한다. 아래는 자동 진단이며, HTML에 원본/v3의 구간을 맞춘 A/B를 열어 직접 비교할 수 있도록 했다.

## 현재 판단

- **악기·비트 보강: 성공 미확인.** 양 후렴에서 음량 정규화 뒤 타격성/저역 proxy가 감소한다. 악기 종류·기타 레이어 수·체감 강도나 보강 실패를 확정하지 않는다.
- **가사·발음: 첫 후렴에 후퇴 의심 지점이 있다.** 원본의 `널 잊겠니`가 v3에서는 `너 있겠니/너 잊겠니`, `삶인데`는 두 전사에서 `사유인데`로 인식됐다. 입력 가사는 동일하며 실제 오발음의 확정 증거는 아니다.
- **음정: 큰 선율 붕괴의 새 근거는 없다.** 같은 피치의 연속을 합친 첫 후렴의 자동 MIDI 순서는 같고, 후렴 음역71–83/추정107BPM/옥타브 초과 도약0도 같다. 미세한 음정(cents), 가창 질감·타이밍·실제 음정 품질은 미확인이다.
- 원본을 기준본으로 보존하고 v3는 직접 청취 전 개선 확정본으로 승격하지 않는다. 추가 개사·음원 편집·생성은 하지 않았다.

## 구간과 조건

| 구간 | 원본 자동 구조 추정 | v3 자동 구조 추정 |
| --- | --- | --- |
| 첫 후렴 | 132.97–169.01초 | 131.84–168.80초 |
| 마지막 후렴 | 221.61–266.41초 | 220.32–262.88초 |

같은 SheetSage2 기설치 CPU 환경의 공개 `score:transcribe`로 두 완성 음원을 음악 악보로 전사했다. 구조·음정은 추정이며 강제정렬·청취 확정이 아니다. 이전 ASR 분절 시각과 달라 최종 신호 비교에는 위 구조 경계를 양쪽에 일관 적용했다. 초기 ASR 기반 분석 자료도 보존했다.

Whisper large-v3-turbo/large-v3를 동일 로컬 GPU 조건, 첫120–180초·마지막210–280초에 각각 실행했다. 가사 prompt/grammar를 주지 않았고 두 모델은 같은 계열이다. 전사 문자열을 실제 오발음·인간 청취 점수로 해석하지 않는다.

## 악기·비트의 신호 진단

16kHz float32 `(L+R)/2` 분석 사본을 사용했다. 원음·MP3·HTML 재생 바이트는 가공하지 않았다. STFT 1024/hop256, 중앙값 HPSS31/31, 분석 시 RMS0.1 정규화를 적용했다. 타격성 자음·보컬도 포함하는 proxy이며 악기 분리 결과가 아니다. 수치가 작다고 기타·드럼이 실제 줄었다고 단정하지 않는다.

| 지표 | 첫 후렴 원본 → v3 | 마지막 후렴 원본 → v3 |
| --- | --- | --- |
| 원래 분석 RMS | -13.74 → -15.49 dBFS | -13.03 → -15.77 dBFS |
| 타격성 전력 비중 proxy | 13.88% → 10.40% | 12.61% → 8.84% |
| 30–150Hz 저역 전력 비중 | 33.12% → 26.49% | 38.91% → 29.76% |
| 정규화 flux95 proxy | 0.2414 → 0.1910 | 0.2412 → 0.1841 |

v3가 더 강한 비트/베이스라는 측정 근거는 나오지 않았다. 재생 볼륨은 두 버전이 공유하지만 체감 loudness 정규화 기능은 아니므로, 듣기 비교에서는 원래 음량 차이를 함께 고려한다.

첫 후렴은 연속 같은 피치를 합치면 피치 순서가 동일하다. 마지막 v3의 구간 시작 앞에서 시작해 경계를 가로지르는 MIDI78 이벤트1개를 제외하면 압축 피치 순서가 같다. 이를 새 음 추가나 오류로 단정하지 않는다. 음 수 차이는 프레이징/전사 분할/구간 경계 차이를 포함한다. 정수 MIDI 전사는 cents·비브라토·보컬 흔들림을 평가하지 않는다.

## HTML 비교 청취

내 작업물 → 해당 음악 → **음원 → 두 버전 A/B 비교 청취**를 사용한다. A는 원본, B는 v3이며 첫 후렴 앞뒤가 들리도록 A131–171초, B129.87–169.87초를 이 브라우저 세션에 보관했다. 곡별 값은 제품 코드에 하드코드하지 않았다. 같은 시각=같은 가창 위치가 아니므로 시작·끝을 각각 조정할 수 있다.

- A/B 전환은 각 구간 시작 기준의 상대 경과 시각을 유지한다. A145 → B143.87 → B145.87 → A147 실기 통과.
- 한 비교 플레이어만 사용하고 다른 음원/영상과 중복 재생하지 않는다. B 일시정지 뒤 구간 처음은 B129.87로 돌아간다.
- 구간끝171초 자동 정지, 새 결과 갱신 시 기존 플레이어 정지, 범위 오류·빈값·중복 SHA 선택 차단을 확인했다.
- 실제 페이지 왕복 후 구간 복원, Paperlogy, 키보드 이동, 숫자 wheel 값 보존/blur, 320px 1열·가로 넘침0·버튼44px을 확인했다.
- 늦은 play Promise가 메타데이터 길이 오류를 성공 문구로 덮는 문제도 실패 회귀를 먼저 재현하고 수정했다.

변경 범위는 canonical/mirror의 works.js·work-detail.html·공통 CSS·작업물 가이드·VM 테스트와 root npm wrapper다. 새 API·의존성·모델·서버 재시작 없이 기존 등록 파일 URL과 단일 재생 규칙을 재사용했다.

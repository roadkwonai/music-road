# 최종본 외 자료 검토·선택 폐기

사용자 범위: 모든 파일 유형을 검토하며 현재 프로그램·모델·최종 결과물·원음·필요한 최소 이력은 유지한다. 서로 다른 이전 초안도 명시 선택 폐기할 수 있으므로 동일 해시인 중복 정리에 한정하지 않는다.

- 기존 artifacts의 보수적 정책은 유지하고 별도 retirement scope를 둔다. 자동 일괄 정리에는 포함하지 않는다. 전체 스캔→유형별 보호/후보 검토→명시 선택→계획→실행→재스캔·보존 검사를 유지한다.
- Work Library 및 제작실 등록 파일, 모든 음악 라이브러리·원음, 현재 모델, 현재 실행 환경과 제작 입력/자산, 원본/최종 해시와 판단 기록은 보호한다. 활성 lease·열린 파일·symlink/hardlink·새로 등록된 최종본·증거 변경은 차단한다. 현재 yue-cli-expansion 작업은 제외한다.
- 검증된 producer의 원음과 최종 납품이 남은 경우에만 렌더 조각·초안·QA 이미지·파생 mix WAV를 폐기한다. 파생 캐시 재생성 필요성을 HTML에 표시하고 고유 최종본은 이름으로 추측해 지우지 않는다.
- 분석·참조 미디어는 출처/원본 해시/분석 JSON·문서와 대표 시트를 보존하는 명시 폐기 프로필로 분리한다. 정리된 영상은 재검토 전에 다시 확보해야 한다는 기록을 남긴다.
- 배포 ZIP은 제품 marker가 있는 과거 설치/검증 패키지만 검증한다. 현재 프로그램·모델은 보존하며 직전 before 복구의 canonical ZIP은 삭제하지 않는다. 일반 사용자 결과물 ZIP은 보호한다.
- 과거 설치 검증 복제본의 현재 canonical 소스/자산과 동일한 파일만 복구 매핑을 남겨 정리한다. 현재 스킬 자산·실행 중 환경·다른 버전 고유 코드는 보호한다.
- 새 경계 회귀를 먼저 추가한다. 공통 검증·nofollow 삭제·잠금·일회 계획·압축 감사 이력을 재사용한다. 독립 검수와 전체 검사 후 실제 HTML에서 삭제하고 회수량/남은 보호 이유를 보고한다.

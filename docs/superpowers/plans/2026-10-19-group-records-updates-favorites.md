# 그룹 제작 기록·업데이트·좋아요

- 그룹 상세 안에 해당 groupId의 메인/이력 요청, AI/결과 요약, 작업·파일 기록을 페이지 단위로 조회·복사한다. 버전 diff는 기존 별도 기능을 유지한다.
- 그룹 단위 좋아요를 프로필 SQLite에 저장한다. 목록/상세 heart, 좋아요 전용 목록, 공개 CLI 조회/저장을 함께 제공한다. 그룹 제거·실패 복구에 좋아요도 포함한다.
- 버전 상태의 명시 확인/업데이트 동작은 기존 공개 업데이터만 호출한다. 설치 대상/명령을 브라우저가 지정하지 않는다. 관리하지 않는 소스는 이유를 표시하고 실행하지 않는다. 진행률을 모르면 불확정 bar, 실제 확인 후 완료·버전을 표시한다.
- 임시 프로필과 가짜 업데이터로 성공·실패·진행/완료·보안 경계를 검증하고, 실제 Ego HTML에서 그룹 격리·복사·좋아요 유지·업데이트 동작을 확인한다. 현재 개발 설치·모델·완성본은 테스트 설치 대상으로 사용하지 않는다.
- canonical music-road-skills와 CLI/Markdown·공통 HTML 가이드를 동기화한다. npm test와 변경 JS 구문·Python 검사를 통과한 후 검증 임시 자료를 정리한다.

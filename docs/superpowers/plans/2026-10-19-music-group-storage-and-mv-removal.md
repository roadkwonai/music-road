# 음악별 저장공간 관리와 AI M/V 전체 정리

사용자 요청: 기본 목록을 제작 음악별로 그룹화하고 기타 자료는 접힌 상세에 모은다. 우측 상단 자동 일괄 정리는 전체 스캔 후 미리보기·확인으로 실행한다. AI M/V 프로젝트는 최종 영상·애니매틱·중간본까지 통째 정리할 수 있게 공개 CLI/HTML/스킬을 연결하고 이번 기존 M/V 작업에 실제 실행한다. 원본 음악·모델·현재 프로그램은 유지한다. 제작실 입력 음원 재생 문제도 수정한다.

## 보존과 삭제 범위

- 일반 자동 정리는 검증된 재생성 캐시와 설치 검증 잔재에 한정한다. 음악의 원본·완성 음원과 현재 프로그램·모델은 계속 보호한다.
- AI M/V 전체 삭제는 일반 캐시와 구분한 명시적 프로젝트 ID 계획으로만 수행한다. 이번 사용자는 애니매틱/영상 결과물을 포함한 기존 AI M/V 프로젝트 전체 정리를 승인했다.
- 삭제 전에 전체 작업 폴더 스캔, 프로젝트 표지·외부 원음·활성 작업·열린 파일·symlink·파일 변경을 검사한다. 삭제 후 원음 SHA와 실제 확보 용량을 확인하고 최소 요약을 프로젝트 밖에 남긴다.
- 의미를 확인할 수 없는 임의 Output 폴더, 다른 음악의 결과물과 연구 자료를 이름만으로 확대 삭제하지 않는다.

## 구현과 검증

1. 음악 source SHA와 기존 WorkLibrary/제작실/생산 manifest 연결로 그룹화한다. 임시 프로젝트·패키지 검증·미연결 자료는 별도 상세로 이동한다.
2. AI M/V 프로젝트 발견·미리보기·전체 삭제를 검증된 루트/일회용 계획으로 구현한다. 기존 캐시 정리와 자동 일괄 계획을 재사용한다.
3. CLI catalogue/dispatcher/HTTP를 연결하고 HTML 기본 화면을 단순화한다. 입력 음원 전달/플레이어 문제는 독립 원인 조사와 회귀로 수정한다.
4. 기존 보호/계획/동시 변경 테스트를 유지하고 그룹 합치기·비음악 분리·M/V 전체 삭제·원음 보존·만료/재사용·자동 스캔 선행을 격리 테스트한다.
5. 실제 Ego 화면에서 음악별 목록·자동 스캔·M/V 전체 삭제·확보 용량·재생 음원 데이터를 검증한다. 기존 사용자 앱/제작 서비스는 종료하지 않는다.
6. 독립 검수 후 승인 범위의 실제 M/V만 새 HTML 기능으로 정리하고 전후 근거를 남긴다. npm/Python/구문/스킬 검증과 문서를 완료한다.

새 의존성·모델 설치·릴리스·Git push는 범위 밖이다. 진행 중 잠금·핀·완료 정책을 유지하며 제작 단계별 효율화는 기존 공통 lifecycle을 보완한다.

# 참조·과거 제작 자료의 선택 정리

현재 앱·모델·원음·최종 영상·수정 코드·검수 판정을 보존한다. 기존 maintenance의 전체 스캔/15분 일회용 계획/명시 선택/확인 실행/dirfd 삭제/회수량/감사 이력을 재사용하고 artifacts 범위만 추가한다. 자동 일괄 정리에는 과거 자료를 자동 포함하지 않는다.

1. 후보와 현재 스킬·프로젝트·납품의 연결을 읽고 허용된 역사적 producer만 지원한다. 일반 qa/before 이름으로 탐색 삭제하지 않는다.
2. 참조 원본은 현재 코퍼스 근거로 유지한다. 캡처/remux는 보존 원본과 모든 스트림 hash가 같을 때만 삭제한다. 추출 프레임은 원본 SHA/추출 manifest/지표·전체 contact sheet/대표 원본 프레임을 보존하고 대량 개별 프레임만 정리한다.
3. 최종 해시 manifest와 실제 납품이 일치하는 QA의 runtime/style 세부 PNG만 대표 프레임과 보고서·sheet를 남기고 정리한다. 최종 경계·자막·동작 증거는 유지한다.
4. 과거 before는 버전별 코드/문서/설정을 유지한다. 보존된 배포 archive에서 byte equality로 복원할 수 있는 중복 binary만 삭제하며 원래 path→archive member·hash를 감사 manifest에 남긴다.
5. 실패·변경·busy·symlink/hardlink·증거 누락·한도 초과를 먼저 회귀 테스트한다. 목록과 삭제 직전 모두 재검증하며 일부 실패도 실제 회수량만 보고한다.
6. CLI/catalog·HTML의 기타 관리에서 종류별 후보/보존 근거를 제공한다. 독립 검수 후 실제 HTML로 선택 계획/실행하고, 파일 상태·보존 hash·논리/할당/디스크 여유를 전후 비교한다.

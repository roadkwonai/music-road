# 공용 캐시 정리와 안전 재시작 검증

사용자가 승인한 범위: 진행 작업 확인, idle 기본 앱 안전 재시작, 과거 공용 영상 캐시 정리, 격리 음악/영상 샘플 자동 정리 확인. 현재 모델/원음/완성본/복구 이력 보존.

1. 기본/별도 프로필 상태와 대기열 기록. 진행 작업이면 종료하지 않는다. 별도 프로필은 공용 캐시와 무관하므로 유지한다.
2. stop의 녹음·파일 이동·준비 상태 누락을 회귀 테스트로 고정하고 보완한다.
3. 고정 앱 데이터/video-cache만 검증하는 공개 video:cache / video:cache-clear 추가. 신규 앱은 이 위치를 사용하지 않으며 과거 생성물 형식/스냅샷/일회용 만료 계획·idle 예약·확인을 적용한다. 임의 파일·모델·결과물 제외, 감사 이력 보존.
4. 종료→PID 종료 확인→동일 설치/데이터로 재시작, 공개 명령으로 캐시 계획 확인 후 정리.
5. 기존 ACE 모델을 재사용한 격리 10초 연주곡과 720p 영상. 편집 중 캐시 보존→완료/TTL0 자동 삭제→다시 렌더/자동 삭제. 원음·완성본·이력 해시, 공용 cache 재발 없음 확인.
6. 전체 테스트/변경 구문/문서·스킬 검사 후 실제 수량·한계 보고. 앱/모델 설치·업데이트·기존 프로젝트 변경은 하지 않는다.

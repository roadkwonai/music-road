# 2026-10-20 0.1.0 재배포 안내

[Road Music](../README.md) · [업데이트](updates.md)

사용자의 명시적 요청으로 앱·CLI·music-road-skills의 버전 상태 검수 수정을 같은 **0.1.0**에 반영해 다시 배포합니다. Git 개발 이력을 다시 초기화하지 않으며, 일반적인 동일 버전 재발행 금지 규칙도 유지합니다.

## 수정 내용

- 현재 설치본이 공개 버전보다 높으면 실제 버전과 수동 전환 사유를 표시합니다. 자동 다운그레이드는 하지 않습니다.
- 정식 배포 없음, 스킬 미설치, 소스 체크아웃 관찰을 구분합니다. 빈 경로에서 스킬 update가 자동 설치하지 않습니다.
- 아직 확인하지 않은 상태와 같은 버전 번호만으로 최신 파일·무결성을 단정하지 않습니다.
- SQLite 버전 관찰 기록, HTML 버튼·안내와 CLI·스킬·사용 가이드를 함께 수정했습니다.
- 업데이트·롤백 검증은 과거 1.4.0 상수 대신 실제 기준 앱·소스의 버전을 읽습니다.
- 설치 폴더가 바뀌어도 프로필에 설정된 검증된 작업 폴더를 연결합니다. 기존 Output·버전 SQLite를 이동·복제하지 않고, 납품 이력을 확인하지 못한 경우 기존 파일 연결 색인을 보존합니다.

설치형 앱의 Python 도구가 서명된 앱 내부에 `.pyc` 캐시를 만들지 않도록 보완했습니다. 실행·버전 확인 뒤에도 앱 서명 검증이 유지되는지 확인합니다. 모델과 미디어 결과는 변경하지 않습니다.

번호와 파일명은 같아도 파일 내용과 체크섬은 바뀝니다. 이전 다운로드를 재사용하지 말고 현재 Release의 새 파일과 같은 Release에 첨부된 체크섬을 함께 확인하세요. 기존 앱·CLI·스킬·로컬 수정은 보존한 뒤 새 빈 설치 경로에서 검증합니다. 이전 다운로드·외부 clone·캐시는 회수되지 않으며 같은 버전은 자동 업데이트 대상으로 표시되지 않습니다.

교체 전 자산·체크섬·Release 메타데이터·태그 대상은 별도 로컬 백업에 보존합니다. [최초 배포 검증](version-reset-20261020-qa-report.md)은 과거 기록이며 그 해시를 새 파일에 적용하면 안 됩니다.

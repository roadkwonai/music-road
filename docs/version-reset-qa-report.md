## 전환과 제한

이전 앱 `v1.4.0`과 첫 CLI `cli-v0.1.0`의 Release·태그·자산은 해시 검증한 백업과 Git bundle로 보존한 뒤 철회했다. 이번 명시적인 초기화에서만 CLI 0.1.0을 새 기준으로 재발행했으며, 이후 동일 버전 재발행은 금지한다. 이미 받은 파일과 캐시는 회수되지 않는다.

기존 1.4.x 앱은 낮은 0.1.0을 자동으로 설치하지 않는다. 옛 CLI 0.1.0도 같은 숫자라 새 버전 알림으로 구분되지 않는 것을 실제로 확인했다. 최초 한 번 [수동 전환 안내](updates.md)에 따라 새 앱과 새 CLI를 설치해야 한다. 사용자 설치본·라이브러리·모델을 이번 시험에서 교체하거나 이동하지 않았다.

Linux 실제 설치, Windows 자동 설치, 새 음악 생성·실제 마이크·청취 품질은 이번 검증 범위가 아니다. Windows 자동 설치는 지원하지 않으며 macOS 앱은 애드혹 서명으로 Apple 공증을 받지 않았다.

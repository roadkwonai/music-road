# ACE 가사·프롬프트 검수 에이전트 요청

사용 가능한 별도 에이전트에 이 파일과 작성자의 검토안을 전달할 때 쓰는 읽기 전용 역할 지침이다. 특정 AI 제품의 에이전트 등록 형식을 가정하지 않는다. 별도 에이전트가 없으면 주 에이전트가 같은 항목을 직접 점검하고 자체 검수라고 밝힌다.

## 목차

- [입력](#입력)
- [역할](#역할)
- [반환](#반환)

## 입력

사용자 원요청, 전체 가사, 원래 생성 JSON, `lyrics:clean` 결과, 최종 caption, 길이·schema 점검 결과, 참고 자료 경로/URL을 받는다. 누락됐으면 그 항목을 특정하고 검수가 완료됐다고 표시하지 않는다.

## 역할

- [공통 지침](../AGENTS.md), [ACE 가이드](../docs/ace-prompt-guide.md), [태그 가이드](../docs/lyrics-tags.md), [검토 규칙](../docs/music-review.md)을 읽는다.
- 요청의 언어·장르·보컬·길이·곡 수·원문 보존 조건을 기준으로 가사와 caption의 일관성을 점검한다.
- 공식 태그와 로드뮤직의 변환·삭제 차이, 실제 가사 손실, caption 512자·가사 4,096자 한계, 지원되지 않는 옵션을 확인한다.
- 후렴 반복이 실제 가사에 있는지, Pre-Chorus·Bridge·Interlude가 곡 목적에 맞는지 확인한다. 모든 태그를 쓰도록 강제하지 않는다.
- 참고한 자료가 실제 주장을 뒷받침하는지, 최근 인기 근거와 창작적 판단이 구분되는지 확인한다.
- 사용자 검토 필요 여부를 원요청과 위임 범위로 판단한다. “가사만 자동”을 전체 자동으로 확대하지 않는다.
- 음악 생성·렌더·모델 설치·작업 중단·파일 수정은 하지 않는다. 검수 결과는 요청자의 승인이나 자동 위임을 대신하지 않는다.

## 반환

1. **판정:** 요청자에게 제시 가능 / 수정 필요 / 확인 불가.
2. **중요 문제:** 가사 줄·태그·JSON 필드 등 문제 위치와 근거, 최소 수정 제안.
3. **검증 범위:** 실제로 점검한 것과 실행·청취하지 않은 것.
4. **다음 단계:** 요청자 검토 대기 또는 명시적 자동 위임 범위 내 생성 가능 여부.

작성자는 수정안을 다시 기술 검증한다. 이미 승인받은 의미를 바꾼 경우 [재검토 기준](../docs/music-review.md#approval)을 적용한다.

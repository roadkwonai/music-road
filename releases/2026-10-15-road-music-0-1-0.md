# Road Music 0.1.0

Road Music 앱과 CLI는 각각 0.1.0부터 독립 버전을 다시 시작합니다. 공통 초기 번호라도 태그·asset·체크섬·설치 경로는 분리하며 앱과 CLI의 번호를 함께 올리지 않습니다.

## 사용자 변경

- 앱 Release는 `v0.1.0` 태그와 `RoadMusic-0.1.0-mac-arm64.dmg`·`RoadMusic-0.1.0-source.zip`으로 배포하며 GitHub Latest는 앱에만 지정합니다.
- 앱의 **가이드 보기**와 CLI의 읽기 전용 `prompt:knowledge`로 CCM·찬송가 리메이크·가사 태그·ACE 작성·검토 규칙을 확인할 수 있습니다. 가이드 조회는 사용자가 준 가사·프롬프트·옵션을 바꾸거나 음악을 생성하지 않습니다.
- CLI는 별도 `cli-v0.1.0` Release 채널을 유지합니다. 새 CLI 0.1.0의 `appVersion: 0.1.0`은 동봉 앱 소스 기준일이며, 설치된 GUI 앱 버전이나 앱 업데이트 대상이 아닙니다.

## 설치 영향

- 기존 1.4.x 앱은 0.1.0보다 높은 번호이므로 자동 업데이트하지 않습니다. 사용자가 0.1.0 DMG를 한 번 수동 설치해야 하며, 설치된 앱·곡·모델·설정을 이 Release가 자동으로 내리거나 변경하지 않습니다.
- 전환한 0.1.0 앱은 0.1.1 이상의 앱 Release만 업데이트 알림 대상으로 처리합니다.
- CLI만 쓰는 경우에는 앱 0.1.0 DMG를 설치할 필요가 없습니다. [CLI 0.1.0 Release](https://github.com/roadkwonai/music-road/releases/tag/cli-v0.1.0)를 사용합니다. 같은 번호의 이전 공개 CLI 0.1.0은 당시 동봉 앱 소스 1.4.0을 보존하는 철회 기록이므로 새 ZIP을 새 폴더에 설치해야 합니다.

## 검증

- 배포 전 `npm test`, 변경 JavaScript 구문 검사, 앱 DMG·소스 ZIP의 버전·체크섬과 GitHub Release asset을 확인합니다.
- 앱 업데이트 검증은 0.1.0 설치본에서 0.1.1 이상 후보만 알리는지, 1.4.x 설치본을 자동으로 전환하지 않는지 확인합니다.
- 새 CLI 0.1.0은 별도 ZIP·체크섬·수동 새 폴더 설치로 검증하며, 철회 전 공개 CLI 0.1.0의 ZIP·체크섬·검증 기록은 보관합니다.

## 제한과 참고

- 앱 자동 업데이트의 실제 설치 검증 범위는 macOS Apple Silicon입니다. Windows 앱 업데이트와 Linux 소스 설치는 별도 검증 대상이며, 앱은 애드혹 서명으로 Apple 공증을 받지 않았습니다.
- 앱과 CLI는 제품별 최신 정식 Release의 바로 다음 버전만 배포할 수 있습니다. 같은 버전 재배포·역행·번호 건너뛰기·다른 제품 태그는 CI가 거부합니다.

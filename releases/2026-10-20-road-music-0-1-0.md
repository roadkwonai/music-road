# Road Music 0.1.0

현재 개발된 음악 제작·영상 제작실·작업 기록·저장공간 관리 기능을 모아 0.1.0부터 새로 배포합니다. 저장소의 main은 현재 소스를 담은 최초 커밋으로 재구성하며, 기존 공개 태그와 Release는 이번 명시적 초기화에서 교체합니다.

## 포함한 기능

- 기존 ACE와 Apple Silicon YuE2 MLX의 음악 제작 및 모델별 가사·프롬프트 가이드.
- 음악별 완성본·버전·프롬프트·결과 이력, 좋아요, 제작 시간과 대기열·예상시간 조회.
- 프로젝트별 SQLite 추적과 보호 대상 확인, 미리보기 후 실행하는 저장공간 정리.
- PC·모바일 HTML 제작실, 스타일·태그 필터, CCM 스타일 설명과 모델별 프롬프트 복사.

## 설치와 전환

- 앱은 `v0.1.0`의 DMG·소스 ZIP, CLI는 `cli-v0.1.0`의 별도 ZIP으로 제공합니다. 앱만 GitHub Latest입니다.
- 과거 0.1.0과 같은 번호이고 0.1.1 이상보다 낮으므로 자동 업데이트 알림으로 새 배포를 구분할 수 없습니다. 최신 Release의 SHA-256을 확인하고 앱은 수동 설치, CLI는 새 빈 폴더에 설치하세요.
- 기존 설치본·모델·음악·영상·개인 설정은 이번 Git/Release 초기화에서 이동·삭제하지 않습니다. 이전 소스 clone은 새 clone으로 전환하고 로컬 수정을 직접 비교해 옮기세요.
- Showreel·JIZURA 등 관리 스킬 묶음은 별도 [music-road-skills 0.1.0](https://github.com/roadkwonai/music-road-skills/releases/tag/v0.1.0)입니다.

## 검증과 제한

배포는 npm 회귀 검사, 소스 업데이트 검사, 앱 서명·DMG 무결성, ZIP·체크섬 검사를 통과해야 공개합니다. macOS 앱은 애드혹 서명이며 Apple 공증을 받지 않았습니다. 이번 작업은 새 음악 생성이나 다른 OS의 실제 설치 검증을 포함하지 않습니다.

이번 초기화 이후 각 제품은 0.1.1부터 독립적으로 증가하며 동일 버전 재배포 금지 규칙을 유지합니다. 이미 내려받은 파일과 외부 clone은 초기화로 회수되지 않습니다.

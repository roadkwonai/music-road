Road Music CLI 0.1.0은 현재 음악·영상 제작 및 관리 기능을 포함하는 새 배포 기준입니다. 앱·CLI·스킬의 버전 번호를 0.1.0으로 맞추되 태그·파일·업데이트 채널은 독립적으로 유지합니다.

## 포함한 기능

- ACE·YuE·YuE2 MLX의 공개 제작 명령, 악보 검토와 단계별 재사용.
- SQLite 기반 프로젝트별 프롬프트·작업 시간·결과·버전·저장공간 추적.
- 음악별 HTML 보관함과 재생·다운로드·정리, CCM·일반 활용 예시와 모델별 가이드.
- 현재 CLI에 맞는 작사·검수·저장공간·제작 기록 스킬과 HTML 제작실 자료.

## 이번 재배포의 수정

2026-10-20 사용자 요청으로 버전 체크·HTML·문서 검수 보완을 같은 0.1.0에 반영해 재배포합니다. 낮은 공개 버전, 배포 없음, 스킬 미설치를 최신 상태와 구분하고 실제 설치 번호를 보존합니다. 동봉 스킬과 휴대형 가이드도 같은 수정본입니다. 이전 ZIP과 체크섬은 백업하며, 이번 예외 뒤 동일 버전 재발행 차단은 유지합니다.

## 설치와 전환

`RoadMusic-CLI-0.1.0.zip`과 같은 Release의 `SHA256SUMS.txt`를 확인하고 새 빈 폴더에 설치하세요. 이전 0.1.0과는 같은 버전이고 0.1.1/0.1.2보다 낮으므로 자동 업데이트로 구분하거나 다운그레이드하지 않습니다. 설치된 앱·CLI·모델·곡·영상과 기존 Git 작업 폴더는 덮어쓰지 않습니다.

태그는 `cli-v0.1.0`이며 앱 Latest를 바꾸지 않습니다. 이전 CLI의 큰 ZIP 검사에서 `UPDATE_VERIFY`가 발생하면 검증을 우회하지 말고 ZIP을 직접 받아 새 폴더에 설치하세요. Node.js 24 LTS와 `npm run setup:cli` 후 새 `cliPath`의 `cli:version`, `schema`, `prompt:knowledge`, `setup:check`로 확인하세요. CLI가 보고하는 `appVersion`은 동봉 소스 버전이며 실행 중 GUI 버전과 구분합니다.

이후 CLI 0.1.1부터 독립적으로 증가하며 동일 버전 덮어쓰기 금지를 유지합니다. 이미 받은 옛 ZIP과 외부 clone은 회수되지 않습니다. 새 모델·음원 생성, Windows·Linux 실제 설치는 이번 배포 검증 범위가 아닙니다.

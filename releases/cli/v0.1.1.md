Road Music 앱 0.1.0과 별도로 배포하는 CLI 0.1.1입니다. 태그는 `cli-v0.1.1`, 자산은 `RoadMusic-CLI-0.1.1.zip`과 `SHA256SUMS.txt`이며 GitHub Latest를 바꾸지 않습니다.

## 음악 엔진

- Apple Silicon의 YuE2-3B MLX 경로를 `yue-mlx` 엔진 ID로 추가했습니다. 설치·생성은 [YuE2 Apple Silicon](https://github.com/roadkwonai/music-road/blob/cli-v0.1.1/docs/yue-mlx.md)을 따르며, 기존 Windows NVIDIA `yue`와 구분합니다.
- 모델별 제작·비교 자료는 `prompt:knowledge --json '{"topic":"models"}'`와 [모델별 제작·비교](https://github.com/roadkwonai/music-road/blob/cli-v0.1.1/docs/model-production-guide.md)에서 읽을 수 있습니다.

## 스킬과 HTML 제작실

- Showreel CD, Showreel MV, JIZURA, Showreel Motion, 공통 HTML 제작실, 업데이트 관리의 6개 스킬을 동봉합니다.
- `skills:status/check/install/update/watch`은 Codex·Antigravity의 스킬 설치·Release 확인을 지원합니다. `motion:handoff`는 생성 완료 음원 또는 빈 프로젝트를 HTML 제작실로 넘기고 다음 `motion:studio` 명령을 반환합니다.
- 스킬 사용 시 해당 요청에서 한 번만 업데이트를 확인합니다. 변화가 없으면 조용히 계속하며 정기 알림과 자동 설치는 등록하지 않습니다.
- 제작실은 CD·리듬 모션·Showreel MV·JIZURA의 실제 샘플 4개를 비교하고, 선택·업로드·청취·자막/영상 검수를 지원합니다.
- 기본 이미지 제작은 Codex `image_gen` 또는 Antigravity의 현재 호스트 도구를 사용합니다. 유료 `gpt-image-2.5` API는 사용자가 명시적으로 요청한 경우에만 별도 사용합니다.

## 설치와 검증

- 소스 체크아웃은 고정 `music-road-skills` submodule을 사용하고 CLI ZIP/npm 배포에는 실제 스킬 파일을 포함합니다. `npm run setup:cli`은 Node 24·의존성·동봉 스킬 설치를 확인합니다.
- `npm test` 201개와 변경 JavaScript 구문 검사를 통과했습니다. 고정 submodule의 실제 스킬 파일을 동봉한 CLI ZIP·체크섬·격리 설치를 검증했습니다. 모델 다운로드·음악 생성·외부 유료 이미지 API·실제 영상 렌더는 이 Release 준비에서 실행하지 않았습니다.

ACE와 YuE2의 작사·프롬프트 준비를 공용 스킬 하나로 안내하고, 선택한 모델에 맞는 공식 근거와 입력 검수를 연결한 CLI 0.1.2입니다. 앱은 0.1.0을 유지하며 GitHub Latest를 변경하지 않습니다.

## 달라진 점

- 공용 진입점을 `skills/road-music/SKILL.md`로 정리했습니다. 기존 `road-music-ace` 경로는 호환 진입점으로 유지합니다.
- YuE2 공식 고정판·현재 자료·모델 카드와 커뮤니티 MLX 자료를 구분해 보관하고, `prompt:knowledge`의 `yue` topic에서 제작 가이드를 조회할 수 있습니다.
- 새 가사의 장면·감정·후렴·호흡 설계와 보컬·악기 역할·편곡 밀도·공간감을 보완했습니다. 외부 자료의 Suno 전용 옵션은 ACE·YuE 옵션으로 옮기지 않습니다.
- ACE의 caption 제한이 YuE에도 적용되는 것처럼 읽히던 태그 설명을 수정했습니다. 긴 스타일 태그의 삭제를 초안부터 점검해 핵심 고음·편곡 지시가 빠지는 문제를 예방하도록 안내합니다.
- 승인된 제목·가사·스타일 보존, 한국어 검수, 자연 EOS·실제 길이·잘림·재생성 비용의 구분을 보완했습니다.

## 설치와 호환성

새 CLI ZIP 전체를 새 위치에 설치하거나 기존 CLI의 업데이트 명령을 사용합니다. 참고 문서 일부만 복사하면 스킬 연결이 끊길 수 있습니다. 음악 생성 모델·기본값·기존 곡 라이브러리는 변경하지 않습니다. 기존 CLI 0.1.1의 YuE2 MLX 및 HTML 모션그래픽 기능과 동봉 스킬은 유지합니다.

## 검증과 한계

소스 테스트 224개와 변경 JavaScript 구문 검사, 문서 링크, 공식 원문 해시와 CLI ZIP의 스킬·가이드 포함 여부를 확인합니다. 실제 모델 다운로드·음원 생성·직접 청취·M1 Max 성능 측정은 이번 릴리스에 포함하지 않으며, 작사·프롬프트 지침이 음악 품질을 보장하지 않습니다.

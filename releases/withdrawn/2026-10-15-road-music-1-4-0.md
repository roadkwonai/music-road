# Road Music 1.4.0

> 철회 기록: 이 노트는 당시 1.4.0 통합 배포의 기록입니다. 현재 앱은 **1.0.0**, CLI는 독립된 **0.1.0**으로 배포합니다. 이 문서는 현재 설치·업데이트 안내가 아닙니다. CLI는 [전용 Release](https://github.com/roadkwonai/music-road/releases/tag/cli-v0.1.0)와 [설치 안내](https://github.com/roadkwonai/music-road/blob/main/docs/cli-install.md)를 사용하세요. 아래의 CLI ZIP·주기적 확인은 당시 앱에 묶인 동작을 뜻합니다.

1.4.0~1.4.3의 업데이트 개선과 최신 AI CLI 제작 가이드를 하나의 **1.4.0 통합 배포본**으로 묶었습니다.

## 주요 변경

- **안전한 업데이트:** 앱·CLI가 시작 시와 15분마다 GitHub 최신 버전을 확인합니다. 크기·SHA-256 검증 후 설치하며 진행 작업과 곡·모델·설정을 보호합니다.
- **실패 복구 강화:** 주석 태그의 실제 커밋을 확인해 Git 소스·의존성을 복구합니다. 새 앱의 목표 버전·PID·준비 상태를 확인한 뒤 성공을 기록하고, 실패하면 이전 앱 복원을 시도합니다.
- **AI 음악 제작 자료 동봉:** ACE 공식 가이드·가사 태그·장르별 옵션 예시·검수 스킬을 CLI와 함께 제공합니다. 기본은 가사·프롬프트 검토 후 생성이며, 전체 자동 위임도 지원합니다.
- **시작과 점검 개선:** 설치 상태별 짧은 AI 프롬프트·기존 CLI 자동 탐색·신규 세션 연결·문서 지도를 제공합니다. macOS 미지원 YuE는 점검에서 제외하고 ACE 오류는 계속 확인합니다.

## 설치와 호환성

**기존 1.4.0~1.4.3 사용자는 새 DMG 또는 CLI 키트를 수동으로 다시 설치하세요.** 같은 버전이나 낮은 버전은 자동 업데이트 대상이 아닙니다. 기존 음악·모델·설정은 별도 데이터 폴더에 유지되며, 업데이트 도우미 개선은 통합 배포본 설치 후 적용됩니다.

당시 Apple Silicon macOS용 DMG·레거시 CLI ZIP·SHA-256 파일을 함께 제공했습니다. 제품 분리 후 이 앱 Release의 소스는 `RoadMusic-1.4.0-source.zip`으로 제공하며, CLI 설치는 위의 전용 Release를 사용합니다. CLI에는 Node.js 24와 `npm ci --include=dev`, 음악 생성에는 별도 엔진·ffmpeg가 필요합니다. 앱은 애드혹 서명이며 Apple 공증이 없어 보안 경고가 나타날 수 있습니다. Windows 자동 설치·비-Git ZIP 자동 소스 교체는 지원하지 않으며 Linux 실제 실행은 검증하지 않았습니다.

## 검증과 참고

- macOS Apple Silicon에서 회귀 테스트 **135개**, 실제 Git 업데이트·실패 복구, 소스 CLI의 CPU/GPU 영상과 패키징 앱의 음원 가져오기·MP3 내보내기·전체 디코드를 통과했습니다.
- 당시 DMG 코드 서명·이미지 무결성, 레거시 CLI ZIP 독립 실행과 배포 파일 SHA-256을 검증했습니다. 음악 재생성·실제 마이크·다른 OS는 이번 재배포에서 다시 시험하지 않았으며, 과거 업데이트 시험은 별도 보고서로 보관합니다.

Road Music CLI는 앱과 별도 제품으로 0.1.0부터 다시 시작합니다. 이번 명시적 재초기화에서는 새 CLI 0.1.0 ZIP에 앱 0.1.0 소스를 동봉합니다. 앱과 CLI가 같은 초기 번호라도 서로의 manifest·태그·asset·체크섬·설치 경로를 공유하지 않습니다.

## 설치와 전환

- 배포 파일은 `RoadMusic-CLI-0.1.0.zip`과 `SHA256SUMS.txt`, 태그는 `cli-v0.1.0`입니다. 앱 Release의 Latest로 지정하지 않습니다.
- 이전 공개 CLI 0.1.0은 앱 소스 1.4.0을 동봉한 철회 기록입니다. 새 키트와 같은 버전 숫자여서 `cli:update:check` 알림만으로 구분되지 않으므로, 새 ZIP을 새 빈 폴더에 수동 설치합니다.
- `cli:update:install --json '{"targetDir":"/새/빈/절대/경로"}'`도 사용할 수 있습니다. 기본 0.1.0 설치 폴더는 현재 Release의 SHA-256과 설치 표식 `archiveSha256`이 일치할 때만 재사용하며, 다르면 기존 폴더를 보존하고 새 경로를 요구합니다.
- 설치가 끝나면 반환된 `cliPath`에서 `--version`, `schema`, `prompt:knowledge`를 확인하고 이후 명령도 그 경로에서 실행합니다. `cli:version`의 `appVersion: 0.1.0`은 동봉 소스 기준일이며 실제 실행 중인 앱 버전은 `service:status`와 `app:state`로 확인합니다.

## 포함한 기능

- CLI 명령·문서·작사 스킬과 CCM·찬송가 리메이크·가사 태그·ACE 작성·검토 지식을 제공합니다. `prompt:knowledge`는 입력을 바꾸거나 음악을 생성하지 않습니다.
- `cli:update:check`와 `cli:update:install`은 CLI 전용 `cli-v*` Release만 조회·설치하며 앱을 시작·교체·재시작하지 않습니다.
- 앱의 `update:*`는 앱 전용입니다. CLI를 설치하거나 업데이트해도 GUI·모델·곡·기존 Git 작업 폴더를 덮어쓰지 않습니다.

## 검증과 제한

- 이 Release는 CLI ZIP·체크섬·새 폴더 설치와 앱 0.1.0 소스 기준을 검증합니다. 과거 공개 CLI 0.1.0의 ZIP·체크섬·검증 기록은 [철회 기록](https://github.com/roadkwonai/music-road/blob/cli-v0.1.0/releases/withdrawn/cli-0-1-0-before-reset.md)으로 보존합니다.
- Windows 자동 설치와 Linux 실제 실행, 음악 생성·청취 품질은 별도 검증 대상입니다.
- 다음 CLI 버전은 0.1.1이며 앱 버전과 공유하지 않습니다. 이번 재초기화 뒤 동일 CLI 버전 재발행·역행·번호 건너뛰기는 허용하지 않습니다.
